  - [x] 1.1 ปัญญาประดิษฐ์และฟิสิกส์เชิงคณิตศาสตร์: ภาพรวม

  - [x] 1.4 โครงสร้างและวัตถุประสงค์ของรายวิชา

- [x] บทที่ 2: พื้นฐานคณิตศาสตร์สำหรับ Machine Learning ในฟิสิกส์
  - [x] 2.1 พีชคณิตเชิงเส้นและเมทริกซ์สำหรับการแปลงข้อมูล
  - [x] 2.2 แคลคูลัสและอนุพันธ์สำหรับการปรับปรุงโมเดล
  - [x] 2.3 สถิติและความน่าจะเป็นสำหรับการวิเคราะห์ข้อมูล
  - [x] 2.4 การหาค่าเหมาะสมที่สุด (Optimization) และฟังก์ชันต้นทุน (Cost Functions)

  - [x] 2.6 การประยุกต์ใช้เครื่องมือคณิตศาสตร์ในปัญหาฟิสิกส์
- [x] บทที่ 3: Machine Learning สำหรับการวิเคราะห์ข้อมูลฟิสิกส์
  - [x] 3.1 การเรียนรู้แบบมีผู้สอน (Supervised Learning): การจำแนกและการถดถอย
  - [x] 3.2 การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning): การจัดกลุ่มและการลดมิติ
  - [x] 3.3 การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning) สำหรับการควบคุมระบบ
  - [x] 3.4 การเลือกคุณลักษณะและการวิศวกรรมคุณลักษณะในข้อมูลฟิสิกส์
  - [x] 3.5 การประเมินประสิทธิภาพของโมเดลและการเลือกโมเดล
  - [x] 3.6 ตัวอย่างการใช้งาน: การวิเคราะห์ข้อมูลจากเครื่องเร่งอนุภาค
- [x] บทที่ 4: Deep Learning และการประยุกต์ใช้ในฟิสิกส์

  - [x] 4.3 โครงข่ายประสาทแบบเกิดซ้ำ (Recurrent Neural Networks) สำหรับข้อมูลอนุกรมเวลา
  - [x] 4.4 Generative Adversarial Networks (GANs) สำหรับการสร้างข้อมูล
  - [x] 4.5 Transfer Learning และการปรับแต่งโมเดลที่ฝึกมาแล้ว
  - [x] 4.6 การประยุกต์ใช้ Deep Learning ในฟิสิกส์ดาราศาสตร์และฟิสิกส์พลังงานสูง

  - [x] 5.4 การสร้างแบบจำลองเชิงประกอบ (Hybrid Models): AI ผสมผสานกับฟิสิกส์
  - [x] 5.5 การประยุกต์ใช้: การจำลองวัสดุและปรากฏการณ์ควอนตัม
- [x] บทที่ 6: การเพิ่มประสิทธิภาพและการควบคุมระบบฟิสิกส์ด้วย AI
