# บทที่ 2: พื้นฐานการเรียนรู้ของเครื่อง

## การเรียนรู้ของเครื่องคืออะไร?

หลังจากที่เราได้ทำความเข้าใจภาพรวมของปัญญาประดิษฐ์ในบทที่ 1 แล้ว ตอนนี้เราจะเจาะลึกไปที่หัวใจสำคัญของ AI ยุคใหม่ นั่นคือ "การเรียนรู้ของเครื่อง" หรือ "Machine Learning (ML)" ลองนึกภาพว่าคุณกำลังฝึกสัตว์เลี้ยงให้ทำตามคำสั่ง คุณไม่ได้เขียนโปรแกรมให้มันทำตามคำสั่งทีละขั้นตอน แต่คุณสอนมันผ่านการให้รางวัลเมื่อมันทำถูก และแก้ไขเมื่อมันทำผิด จนกระทั่งมันเรียนรู้ที่จะทำตามคำสั่งได้ด้วยตัวเอง

Machine Learning ก็ทำงานในลักษณะเดียวกัน โดยเป็นสาขาย่อยของ AI ที่มุ่งเน้นการสร้างระบบที่สามารถเรียนรู้จากข้อมูลได้โดยไม่ต้องถูกตั้งโปรแกรมอย่างชัดเจน [1] แทนที่จะบอกคอมพิวเตอร์ว่าต้องทำอะไรทีละขั้น เราจะให้ข้อมูลจำนวนมากแก่คอมพิวเตอร์ และปล่อยให้มันค้นหารูปแบบ ความสัมพันธ์ และกฎเกณฑ์จากข้อมูลเหล่านั้นด้วยตัวเอง เมื่อเรียนรู้แล้ว ระบบก็จะสามารถนำความรู้นั้นไปใช้ในการตัดสินใจ คาดการณ์ หรือทำงานต่างๆ ได้

หัวใจสำคัญของ Machine Learning คือการที่ระบบสามารถ "เรียนรู้" และ "ปรับปรุง" ประสิทธิภาพของตัวเองได้เมื่อได้รับข้อมูลใหม่ๆ หรือเมื่อทำผิดพลาด ยิ่งมีข้อมูลมากเท่าไหร่ ระบบก็จะยิ่งเรียนรู้ได้ดีขึ้นและแม่นยำมากขึ้นเท่านั้น

## ประเภทของการเรียนรู้ของเครื่อง

Machine Learning สามารถแบ่งออกเป็นสามประเภทหลักๆ ตามวิธีการเรียนรู้และลักษณะของข้อมูลที่ใช้:

### 1. การเรียนรู้แบบมีผู้สอน (Supervised Learning)

การเรียนรู้แบบมีผู้สอนเป็นประเภทที่พบได้บ่อยที่สุดใน Machine Learning ในการเรียนรู้แบบนี้ ระบบจะถูกฝึกด้วยชุดข้อมูลที่มี "ป้ายกำกับ" (labeled data) ซึ่งหมายความว่าข้อมูลแต่ละส่วนจะมีคำตอบที่ถูกต้องกำกับอยู่แล้ว [2] ลองนึกภาพว่าคุณกำลังสอนคอมพิวเตอร์ให้แยกแยะระหว่างรูปภาพแมวกับสุนัข คุณจะให้รูปภาพจำนวนมากแก่คอมพิวเตอร์ โดยแต่ละรูปจะระบุไว้อย่างชัดเจนว่าเป็น "แมว" หรือ "สุนัข" คอมพิวเตอร์จะเรียนรู้จากคู่ข้อมูลเหล่านี้เพื่อสร้างแบบจำลองที่สามารถคาดการณ์ป้ายกำกับของข้อมูลใหม่ที่ไม่เคยเห็นมาก่อนได้

**ตัวอย่างการใช้งาน:**
-   **การจำแนกประเภท (Classification):** การทำนายว่าข้อมูลใหม่จัดอยู่ในหมวดหมู่ใด เช่น การจำแนกอีเมลว่าเป็นสแปมหรือไม่ การวินิจฉัยโรคจากอาการ หรือการระบุว่ารูปภาพเป็นแมวหรือสุนัข
-   **การถดถอย (Regression):** การทำนายค่าตัวเลขต่อเนื่อง เช่น การคาดการณ์ราคาบ้านจากขนาดและทำเล การทำนายอุณหภูมิในวันพรุ่งนี้ หรือการคาดการณ์ผลผลิตทางการเกษตร

**อัลกอริทึมที่พบบ่อย:**
-   Linear Regression
-   Logistic Regression
-   Support Vector Machines (SVM)
-   Decision Trees
-   Random Forests

### 2. การเรียนรู้แบบไม่มีผู้สอน (Unsupervised Learning)

ตรงข้ามกับการเรียนรู้แบบมีผู้สอน การเรียนรู้แบบไม่มีผู้สอนจะใช้ชุดข้อมูลที่ "ไม่มีป้ายกำกับ" (unlabeled data) [2] นั่นหมายความว่าระบบจะต้องค้นหารูปแบบ โครงสร้าง หรือความสัมพันธ์ที่ซ่อนอยู่ในข้อมูลด้วยตัวเองโดยไม่มีคำตอบที่ถูกต้องให้ คอมพิวเตอร์จะพยายามจัดกลุ่มข้อมูลที่มีลักษณะคล้ายกันเข้าด้วยกัน หรือลดความซับซ้อนของข้อมูลเพื่อเปิดเผยโครงสร้างพื้นฐาน

**ตัวอย่างการใช้งาน:**
-   **การจัดกลุ่ม (Clustering):** การจัดกลุ่มลูกค้าที่มีพฤติกรรมการซื้อคล้ายกัน การจัดกลุ่มเอกสารที่มีเนื้อหาใกล้เคียงกัน หรือการจัดกลุ่มยีนที่มีฟังก์ชันคล้ายกัน
-   **การลดมิติ (Dimensionality Reduction):** การลดจำนวนตัวแปรในชุดข้อมูลโดยยังคงรักษาข้อมูลสำคัญไว้ เช่น การลดความซับซ้อนของรูปภาพเพื่อการประมวลผลที่เร็วขึ้น
-   **การค้นหากฎความสัมพันธ์ (Association Rule Mining):** การค้นหาความสัมพันธ์ระหว่างรายการต่างๆ เช่น "ลูกค้าที่ซื้อขนมปังมักจะซื้อนมด้วย"

**อัลกอริทึมที่พบบ่อย:**
-   K-Means Clustering
-   Principal Component Analysis (PCA)
-   Apriori Algorithm

### 3. การเรียนรู้แบบเสริมกำลัง (Reinforcement Learning)

การเรียนรู้แบบเสริมกำลังเป็นประเภทที่แตกต่างออกไป โดยระบบจะเรียนรู้ผ่านการลองผิดลองถูกในสภาพแวดล้อมแบบโต้ตอบ [2] ระบบ (หรือที่เรียกว่า "เอเจนต์") จะทำการกระทำบางอย่างในสภาพแวดล้อม และจะได้รับ "รางวัล" (reward) หากการกระทำนั้นนำไปสู่ผลลัพธ์ที่ต้องการ หรือ "การลงโทษ" (penalty) หากการกระทำนั้นไม่เป็นที่ต้องการ เป้าหมายของเอเจนต์คือการเรียนรู้กลยุทธ์ที่จะเพิ่มรางวัลสะสมสูงสุดเมื่อเวลาผ่านไป

ลองนึกภาพการฝึกสุนัขให้คาบของเล่นมาให้ เมื่อสุนัขคาบของเล่นมาให้ คุณให้ขนมเป็นรางวัล เมื่อมันไม่คาบมาให้ คุณไม่ให้รางวัล สุนัขจะเรียนรู้ว่าการคาบของเล่นมาให้จะทำให้มันได้รางวัล และจะทำพฤติกรรมนั้นซ้ำๆ

**ตัวอย่างการใช้งาน:**
-   **การเล่นเกม:** AI ที่สามารถเล่นหมากรุก โกะ หรือวิดีโอเกมได้อย่างเหนือชั้นกว่ามนุษย์
-   **หุ่นยนต์:** การสอนหุ่นยนต์ให้เดิน หยิบจับสิ่งของ หรือทำงานที่ซับซ้อนในสภาพแวดล้อมที่ไม่แน่นอน
-   **ระบบขับขี่อัตโนมัติ:** การสอนรถยนต์ให้ตัดสินใจในการขับขี่ เช่น การเปลี่ยนเลน การเบรก หรือการเร่งความเร็ว

**อัลกอริทึมที่พบบ่อย:**
-   Q-Learning
-   SARSA
-   Deep Q-Networks (DQN)

## กระบวนการทำงานของ Machine Learning

ไม่ว่าจะเป็นการเรียนรู้ประเภทใด กระบวนการทำงานของ Machine Learning โดยทั่วไปจะประกอบด้วยขั้นตอนหลักๆ ดังนี้:

1.  **การรวบรวมข้อมูล (Data Collection):** รวบรวมข้อมูลที่เกี่ยวข้องกับปัญหาที่เราต้องการแก้ไข เช่น รูปภาพพืชที่เป็นโรค ข้อมูลสภาพอากาศ หรือข้อมูลคุณภาพดิน
2.  **การเตรียมข้อมูล (Data Preparation):** ทำความสะอาดข้อมูล (จัดการกับข้อมูลที่หายไปหรือผิดปกติ) แปลงข้อมูลให้อยู่ในรูปแบบที่เหมาะสม และแบ่งข้อมูลออกเป็นชุดฝึก (training set) และชุดทดสอบ (test set)
3.  **การเลือกแบบจำลอง (Model Selection):** เลือกอัลกอริทึม Machine Learning ที่เหมาะสมกับประเภทของปัญหาและข้อมูล
4.  **การฝึกฝนแบบจำลอง (Model Training):** ป้อนชุดข้อมูลฝึกให้กับแบบจำลอง เพื่อให้แบบจำลองเรียนรู้รูปแบบและปรับพารามิเตอร์ภายใน
5.  **การประเมินผลแบบจำลอง (Model Evaluation):** ใช้ชุดข้อมูลทดสอบเพื่อประเมินประสิทธิภาพของแบบจำลอง โดยดูจากความแม่นยำ ความถูกต้อง หรือตัวชี้วัดอื่นๆ
6.  **การปรับแต่งแบบจำลอง (Model Tuning):** หากประสิทธิภาพยังไม่เป็นที่น่าพอใจ อาจมีการปรับพารามิเตอร์ของแบบจำลอง หรือลองใช้อัลกอริทึมอื่น
7.  **การนำไปใช้งาน (Deployment):** เมื่อแบบจำลองมีประสิทธิภาพที่ต้องการ ก็จะถูกนำไปใช้งานจริงในแอปพลิเคชันหรือระบบต่างๆ เพื่อทำการคาดการณ์หรือตัดสินใจ

## สรุป

Machine Learning เป็นรากฐานสำคัญของปัญญาประดิษฐ์ยุคใหม่ที่ช่วยให้คอมพิวเตอร์สามารถเรียนรู้จากข้อมูลและปรับปรุงตัวเองได้ การทำความเข้าใจประเภทหลักๆ ของ Machine Learning และกระบวนการทำงานของมันเป็นสิ่งจำเป็นในการนำ AI ไปประยุกต์ใช้ในโลกแห่งความเป็นจริง โดยเฉพาะอย่างยิ่งในภาคการเกษตรที่เราจะสำรวจเพิ่มเติมในบทถัดไป
