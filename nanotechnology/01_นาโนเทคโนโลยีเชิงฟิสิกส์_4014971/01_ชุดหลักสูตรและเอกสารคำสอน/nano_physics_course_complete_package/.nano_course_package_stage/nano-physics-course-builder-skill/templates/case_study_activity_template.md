## ความพร้อมและความปลอดภัย

ระบุว่ากิจกรรมเป็นการวิเคราะห์ข้อมูล/กรณีศึกษา หรือเป็นกิจกรรมจริงที่ผ่านการอนุมัติแล้ว หากเกี่ยวข้องกับวัสดุนาโน ให้เชื่อมไปยัง SOP, SDS, การประเมินความเสี่ยง และระบบจัดการของเสียของหน่วยงาน ไม่ใช้แม่แบบนี้เป็นใบปฏิบัติการสารเคมี

## ใบกรณีศึกษา

### สถานการณ์

[นำเสนอข้อเท็จจริงที่มี พร้อมระบุข้อเท็จจริงที่ขาดอย่างตั้งใจ เช่น ไม่มี control ไม่ระบุจำนวนซ้ำ ไม่ทราบเงื่อนไขการวัด หรือไม่มีข้อมูลการสัมผัส/ของเสีย]

### Claim ที่ต้องวิเคราะห์

> “[ข้อความกล่าวอ้างจากผลิตภัณฑ์/ทีมวิจัย/สื่อ]”

### ภารกิจของกลุ่ม

1. แยก claim หลักออกจากข้อมูลหรือผลวัดที่มี
2. เชื่อม claim กับโครงสร้าง สมบัติ หรือกลไกทางฟิสิกส์ที่เป็นไปได้
3. ระบุหลักฐานที่มี หลักฐานที่ขาด และ control ที่จำเป็น
4. ระบุความไม่แน่นอน ความเสี่ยง ผู้มีส่วนได้ส่วนเสีย และ safeguards
5. เขียนข้อเสนอแบบมีเงื่อนไข พร้อมหลักฐานขั้นต่ำ 3 รายการก่อนตัดสินใจต่อ

## แผ่นงาน Claim–Evidence–Uncertainty–Decision

| ช่อง | คำถามนำ | คำตอบกลุ่ม |
|---|---|---|
| Claim | ข้อกล่าวอ้างคืออะไร? คำใดกว้างหรือเด็ดขาดเกินหลักฐาน? |  |
| Structure & Physics | โครงสร้าง/สมบัติ/เงื่อนไขใดอาจเกี่ยวข้องกับกลไก? |  |
| Evidence ที่มี | อะไรคือผลวัดจริง? มีหน่วย เงื่อนไข และจำนวนซ้ำหรือไม่? |  |
| Evidence ที่ขาด | ต้องวัดอะไรเพิ่ม? ต้องมี control และ metadata ใด? |  |
| Uncertainty & Risk | แหล่งความไม่แน่นอน ความเสี่ยง และผู้รับผลกระทบคือใคร? |  |
| Decision | ภายใต้เงื่อนไขใดจึงควรทดลองใช้ พัฒนาต่อ หรือชะลอ? |  |

### แม่แบบข้อเสนอแบบมีเงื่อนไข

> “จากหลักฐานที่มีในขณะนี้ ทีมของเราเห็นว่า **[ข้อเสนอ]** ภายใต้เงื่อนไข **[เงื่อนไข]** อย่างไรก็ตาม ยังไม่ควรสรุปว่า **[claim ที่ยังไม่รองรับ]** จนกว่าจะมีหลักฐานเพิ่มเติมเรื่อง **[หลักฐาน]** และมีมาตรการ **[safeguard]**”

## ธนาคารคำถามกระตุ้นความคิด

### Claim และหลักฐาน

1. ประโยคใดเป็นสิ่งที่วัดได้ และประโยคใดเป็นการตีความหรือคำโฆษณา?
2. คำว่า “ปลอดภัย”, “จำเพาะ”, “มีประสิทธิภาพ”, หรือ “ยาวนาน” ต้องนิยามด้วยตัวชี้วัดใด?
3. หลักฐานที่มีรองรับ claim ในขอบเขตใด และไม่รองรับอะไร?

### ฟิสิกส์และการวัด

4. ขนาด รูปร่าง พื้นผิว อินเทอร์เฟซ หรือสภาพแวดล้อมเกี่ยวข้องกับกลไกอย่างไร?
5. เครื่องมือใดตอบคำถามได้โดยตรง และเครื่องมือนั้นตอบอะไรไม่ได้?
6. control ที่เหมาะสมที่สุดคืออะไร? ตัวแปรใดควรคงที่?

### ความไม่แน่นอนและความรับผิดชอบ

7. ความแปรปรวนเกิดจากการสุ่มตัวอย่าง การเตรียมตัวอย่าง เครื่องมือ หรือการวิเคราะห์ข้อมูลหรือไม่?
8. ใครได้รับประโยชน์ ใครรับความเสี่ยง และของเสียไปที่ใด?
9. ถ้ามีทรัพยากรจำกัด หลักฐาน 3 รายการใดมีค่าที่สุดก่อนตัดสินใจขั้นต่อไป?
10. ข้อเสนอของทีมจะเฉพาะเจาะจง ตรวจสอบได้ และเป็นธรรมขึ้นได้อย่างไร?

## Feedback แบบรวดเร็ว

| มิติ | คำถาม feedback |
|---|---|
| Claim กว้างเกินไป | “คำนี้นิยามและวัดอย่างไร?” |
| เครื่องมือไม่ตรงคำถาม | “ก่อนเลือกเครื่องมือ เราต้องวัดอะไรให้ชัด?” |
| ข้ามความไม่แน่นอน | “ถ้าดูข้อมูลรายซ้ำหรือ error bar ข้อสรุปยังเหมือนเดิมหรือไม่?” |
| มองข้ามความเสี่ยง | “ใครสัมผัสวัสดุในแต่ละช่วงของวงจรชีวิต?” |
| ยังไม่พร้อมตัดสินใจ | “ข้อมูลขั้นต่ำใดลดความไม่แน่นอนได้มากที่สุด?” |
