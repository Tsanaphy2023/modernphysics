# Research Notes: AI, ML, DL, Neural Networks

## Source 1: IBM - AI vs. Machine Learning vs. Deep Learning vs. Neural Networks
URL: https://www.ibm.com/think/topics/ai-vs-machine-learning-vs-deep-learning-vs-neural-networks

### Key Definitions:

**Artificial Intelligence (AI)**
- ระบบที่กว้างที่สุด ใช้จำแนกเครื่องจักรที่เลียนแบบความฉลาดของมนุษย์
- ใช้การทำนายและระบบอัตโนมัติเพื่อเพิ่มประสิทธิภาพและแก้ไขปัญหาที่ซับซ้อน
- ตัวอย่าง: การรู้จำใบหน้า, การรู้จำเสียง, การตัดสินใจ, การแปลภาษา

**Categories of AI:**
1. Artificial Narrow Intelligence (ANI) - "Weak AI"
   - ทำงานเฉพาะเจาะจง เช่น ชนะเกมหมากรุก
   - ตัวอย่าง: Siri, Alexa, chatbots
   
2. Artificial General Intelligence (AGI) - "Strong AI"
   - ทำงานได้เทียบเท่ามนุษย์
   - ยังไม่มีอยู่จริง
   
3. Artificial Super Intelligence (ASI)
   - เหนือกว่าความฉลาดของมนุษย์
   - ยังไม่มีอยู่จริง

**Machine Learning (ML)**
- เป็น subset ของ AI
- ช่วยในการเพิ่มประสิทธิภาพและทำนายผล
- Classic ML ต้องการการแทรกแซงของมนุษย์ในการกำหนด features
- ต้องการข้อมูลที่มีโครงสร้างมากกว่า
- ตัวอย่าง: Amazon ใช้แนะนำสินค้าตามประวัติการซื้อ

**Types of Machine Learning:**
1. Supervised Learning - ใช้ labeled data
2. Unsupervised Learning - ไม่ต้องการ labeled data
3. Reinforcement Learning - เรียนรู้จากการโต้ตอบกับสิ่งแวดล้อม
4. Online Learning - อัพเดทโมเดลเมื่อมีข้อมูลใหม่

**Deep Learning (DL)**
- เป็น subset ของ Machine Learning
- ทำ feature extraction อัตโนมัติ ลดการแทรกแซงของมนุษย์
- สามารถใช้ข้อมูลขนาดใหญ่ (big data)
- ใช้กับข้อมูลที่ไม่มีโครงสร้าง (unstructured data) เช่น ข้อความ, รูปภาพ
- ต้องการข้อมูลมากกว่า ML เพื่อเพิ่มความแม่นยำ
- ใช้กับงานที่ซับซ้อน เช่น virtual assistants, fraud detection
- มากกว่า 80% ของข้อมูลองค์กรเป็น unstructured data

**Neural Networks**
- เป็น subset ของ Machine Learning
- เป็นกระดูกสันหลังของ Deep Learning
- เลียนแบบการทำงานของเซลล์ประสาทในสมอง
- ประกอบด้วย: input layer, hidden layers, output layer
- แต่ละ node มี weight และ threshold value
- ตัวอย่าง: Google's search algorithm

**Difference between Deep Learning and Neural Networks:**
- "Deep" หมายถึงความลึกของ layers ใน neural network
- Neural network ที่มีมากกว่า 3 layers (รวม input และ output) ถือเป็น deep learning
- Deep neural networks ส่วนใหญ่เป็น feed-forward (ไหลทิศทางเดียว)
- สามารถ train ผ่าน backpropagation (ย้อนกลับจาก output ไป input)

- มากกว่า 80% ของข้อมูลองค์กรเป็น unstructured data
