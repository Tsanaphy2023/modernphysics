## 5.1 ข้อจำกัดของปัญญาประดิษฐ์แบบดั้งเดิมในงานฟิสิกส์

การเรียนรู้ของเครื่อง (Machine Learning) แบบดั้งเดิมอาศัยการเรียนรู้จากข้อมูลจำนวนมาก (Data-driven approach) อย่างไรก็ตาม ในงานวิจัยทางฟิสิกส์และวิศวกรรม ข้อมูลการทดลองมักมีจำกัด มีสัญญาณรบกวนสูง (Noise) และบางครั้งการเก็บข้อมูลทำได้ยากหรือมีต้นทุนสูง นอกจากนี้ โครงข่ายประสาทเทียมทั่วไป (Standard Neural Networks) มักละเมิดกฎอนุรักษ์ทางฟิสิกส์พื้นฐาน เช่น กฎการอนุรักษ์พลังงานหรือโมเมนตัม ทำให้ผลลัพธ์ที่ได้ขาดความน่าเชื่อถือในเชิงทฤษฎี [1]

เพื่อเอาชนะข้อจำกัดดังกล่าว จึงเกิดการพัฒนา **โครงข่ายประสาทเทียมที่คำนึงถึงฟิสิกส์ (Physics-Informed Neural Networks: PINNs)** ซึ่งหลอมรวมกฎทางฟิสิกส์ที่อยู่ในรูปสมการอนุพันธ์ย่อย (Partial Differential Equations: PDEs) เข้ากับฟังก์ชันสูญเสีย (Loss Function) ของโครงข่ายประสาทเทียมโดยตรง [2]

## 5.2 สถาปัตยกรรมและการสร้างฟังก์ชันสูญเสียของ PINNs

ในกรอบการทำงานของ PINNs เน็ตเวิร์กจะทำหน้าที่ประมาณค่าฟังก์ชันคำตอบ $\hat{u}(x, t; \boldsymbol{\theta})$ โดยใช้พารามิเตอร์น้ำหนักและไบอัส $\boldsymbol{\theta}$ ฟังก์ชันสูญเสียรวม (Total Loss Function) ประกอบด้วย 3 ส่วนหลัก

$$\mathcal{L}_{total} = \mathcal{L}_{data} + \lambda_{pde} \mathcal{L}_{pde} + \lambda_{ic} \mathcal{L}_{ic}$$

เมื่อ
1. **$\mathcal{L}_{data}$:** ความสูญเสียจากข้อมูลการวัดจริง (ถ้ามี)
2. **$\mathcal{L}_{pde}$:** ความสูญเสียจากการสอดคล้องกับสมการอนุพันธ์ย่อยในโดเมน (Collocation Points) ซึ่งคำนวณผ่าน Automatic Differentiation
3. **$\mathcal{L}_{ic}$:** ความสูญเสียจากเงื่อนไขเริ่มต้น (Initial Conditions) และเงื่อนไขขอบ (Boundary Conditions)

ภาพที่ 5.1 แสดงการลดลงของฟังก์ชันสูญเสียในช่วงการฝึกของ PINNs

## 5.3 ตัวอย่างการคำนวณอย่างละเอียด (Worked Example Solving 1D Burgers' Equation)

**โจทย์ปัญหา** พิจารณาสมการเบอร์เกอร์ 1 มิติ (1D Burgers' Equation) ซึ่งเป็นสมการต้นแบบของพลวัตของไหลที่ไม่เป็นเชิงเส้น

$$\frac{\partial u}{\partial t} + u \frac{\partial u}{\partial x} = \nu \frac{\partial^2 u}{\partial x^2}$$

เมื่อกำหนดให้ $\nu = 0.01/\pi$ พร้อมเงื่อนไขขอบและเงื่อนไขเริ่มต้น จงใช้ PINNs ในการเรียนรู้ฟังก์ชันคำตอบ $u(x, t)$ โดยอาศัย Automatic Differentiation ในการคำนวณอนุพันธ์ย่อยเทียบกับพิกัด $x$ และ $t$ [3]

## 5.4 ห้องปฏิบัติการเชิงคำนวณ การจำลอง PINNs ด้วย PyTorch

ในห้องปฏิบัติการนี้ เราจะพัฒนาโปรแกรม Python โดยใช้ PyTorch เพื่อสร้างและฝึกโครงข่ายประสาทเทียมในการแก้สมการอนุพันธ์เชิงความร้อน (1D Heat Equation)

### คำอธิบายโค้ด Python Lab 
โค้ดด้านล่างสร้าง Neural Network ขนาดเล็ก นิยามฟังก์ชันคำนวณอนุพันธ์ด้วย Autograd และสร้าง Loss function ที่บังคับให้คำตอบสอดคล้องกับสมการความร้อน $\frac{\partial u}{\partial t} = \alpha \frac{\partial^2 u}{\partial x^2}$

```python
import torch
import torch.nn as nn
import numpy as np

# นิยามโครงข่ายประสาทเทียมสำหรับ PINN
class PINN(nn.Module):
    def __init__(self):
        super(PINN, self).__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 20),
            nn.Tanh(),
            nn.Linear(20, 20),
            nn.Tanh(),
            nn.Linear(20, 1)
        )
        
    def forward(self, x, t):
        inputs = torch.cat([x, t], dim=1)
        return self.net(inputs)

def pde_residual(model, x, t, alpha=0.01):
    x.requires_grad_(True)
    t.requires_grad_(True)
    u = model(x, t)
    
    # คำนวณอนุพันธ์ด้วย Automatic Differentiation
    u_t = torch.autograd.grad(u, t, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    u_x = torch.autograd.grad(u, x, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    u_xx = torch.autograd.grad(u_x, x, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    
    # สมการความร้อน: u_t - alpha * u_xx = 0
    residual = u_t - alpha * u_xx
    return residual

# การสร้างจุดทดสอบ (Collocation Points)
torch.manual_seed(42)
x_collocation = torch.rand(500, 1) * 2.0 - 1.0
t_collocation = torch.rand(500, 1)

model = PINN()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

# วนลูปฝึกสอนโมเดล (Training Loop)
for epoch in range(100):
    optimizer.zero_grad()
    
    # คำนวณ PDE residual loss
    res = pde_residual(model, x_collocation, t_collocation)
    loss_pde = torch.mean(res**2)
    
    loss_pde.backward()
    optimizer.step()
    
    if (epoch + 1) % 20 == 0:
        print(f"Epoch [{epoch+1}/100], PDE Loss: {loss_pde.item():.6f}")

print("PINN Training Lab Completed Successfully.")
```
