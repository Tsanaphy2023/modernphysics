# ผลการตรวจสอบ eBook

ตรวจสอบเมื่อ 14 สิงหาคม 2569

- เปิดไฟล์ HTML ได้สำเร็จและหน้าแรกแสดงชื่อรายวิชา สถานะ eBook และปุ่มพิมพ์/บันทึก PDF ได้
- มีสารบัญแบบกดได้ครอบคลุม วิธีใช้เอกสาร, CLOs, แผน 15 สัปดาห์, บทที่ 1–10, ภาคผนวก และเอกสารอ้างอิง
- โครงสร้างเนื้อหาสอดคล้องกับแผนการสอน: มาตราส่วน, สมบัติขึ้นกับขนาด, การออกแบบ/สังเคราะห์เชิงแนวคิด, การตรวจวิเคราะห์, ข้อมูลและความไม่แน่นอน, Lab/Data Lab, การใช้ประโยชน์อย่างรับผิดชอบ, โครงงาน, การประเมินผล และการพัฒนารายวิชา
- มีส่วน Data Lab, แนวทางอ่านโค้ด, แบบฝึกหัด/แนวเฉลยย่อ, และภาคผนวกสำหรับการใช้งานในการสอน
- เอกสารระบุชัดว่าเป็นเอกสารการเรียนรู้/วิเคราะห์ข้อมูล ไม่ใช่คู่มือสังเคราะห์วัสดุนาโน และกำหนดให้กิจกรรมจริงต้องผ่าน SOP, SDS และการประเมินความเสี่ยง
- ส่วนเอกสารอ้างอิงรวมแหล่งวิชาการและหน่วยงาน ได้แก่ NNI, PMC, UNC และ NIOSH

ข้อสังเกต: การแยกหน้าของเอกสารสำหรับการพิมพ์ขึ้นกับขนาดกระดาษและการตั้งค่าเบราว์เซอร์ของผู้ใช้ แต่ CSS สำหรับสื่อสิ่งพิมพ์และปุ่มสั่งพิมพ์รวมอยู่ใน eBook แล้ว
