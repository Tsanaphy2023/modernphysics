# Science AI Education Skill

This skill provides comprehensive workflows and procedural knowledge for creating professional science education materials, integrating Artificial Intelligence (MediaPipe) and Computer Vision (OpenCV ArUco) into secondary school physics and STEM curricula.

## Core Capabilities

1. **Academic Book & Textbook Production**: Writing and structuring multi-chapter academic books formatted in Markdown and LaTeX (XeLaTeX for Thai font support), adhering to the **PhysMath Series** design standards (Navy/Cyan/Amber theme).
2. **AI & Computer Vision Project Development**: Building practical Python applications using OpenCV ArUco markers for scale calibration and MediaPipe for hand/object tracking (e.g., Smart Ruler, Projectile Motion, Simple Harmonic Motion, 2D Collision).
3. **Curriculum & Lesson Plan Design**: Creating structured Active Learning lesson plans, student worksheets, quizzes, achievement tests, and rubric scoring frameworks.
4. **Teacher Training & Workshop Materials**: Designing 1-day teacher training workshops, complete with Setup Checklists, Q&A guides for instructors, post-workshop mentoring plans, and professional slide decks with speaker notes.

---

## Workflow Instructions

When tasked with creating a science AI education resource or STEM curriculum:

1. **Define Scope and Objectives**: Identify the target audience, subject area (Physics, Computer Science, STEM), and core learning outcomes.
2. **Develop Core Content & Projects**: Write textbook chapters and corresponding Python code implementing ArUco markers and MediaPipe for real-time digital data logging.
3. **Design Pedagogical Materials**: Use templates from `templates/` to generate lesson plans, student worksheets, evaluation rubrics, and achievement tests.
4. **Create Professional Presentations**: Initialize slide projects using slide tools, applying the PhysMath visual style and drafting concise speaker notes.
5. **Package Deliverables**: Compile textbooks, teacher guides (`Teachers_Guide_Physics_AI.md` / `.pdf`), code files, and presentation links into comprehensive packages.

---

## Bundled Resources

- **`scripts/`**: Executable Python code for data analysis and curve fitting (e.g., `calc_projectile.py`).
- **`templates/`**: Standardized templates for lesson plans (`lesson_plan_template.md`), worksheets, and rubrics.
- **`references/`**: Design and styling guides (`physmath_style_guide.md`) for academic publishing and presentations.
