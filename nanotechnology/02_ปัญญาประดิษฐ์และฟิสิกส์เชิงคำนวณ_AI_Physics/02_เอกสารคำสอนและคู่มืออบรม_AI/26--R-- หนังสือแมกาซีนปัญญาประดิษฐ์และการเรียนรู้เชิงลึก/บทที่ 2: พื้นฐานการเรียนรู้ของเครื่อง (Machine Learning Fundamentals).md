# บทที่ 2: พื้นฐานการเรียนรู้ของเครื่อง (Machine Learning Fundamentals)

## 2.1 Machine Learning คืออะไร?

Machine Learning (ML) หรือการเรียนรู้ของเครื่อง เป็นสาขาหนึ่งของปัญญาประดิษฐ์ที่เน้นการสร้างระบบที่สามารถเรียนรู้และปรับปรุงประสิทธิภาพได้เองจากข้อมูล โดยไม่ต้องถูกโปรแกรมอย่างชัดเจนสำหรับทุกสถานการณ์

### คำนิยามของ Machine Learning

**Arthur Samuel (1959)** ให้คำนิยามว่า: *"Machine Learning เป็นสาขาการศึกษาที่ให้คอมพิวเตอร์มีความสามารถในการเรียนรู้โดยไม่ต้องถูกโปรแกรมอย่างชัดเจน"*

**Tom Mitchell (1997)** ให้คำนิยามที่แม่นยำกว่า: *"โปรแกรมคอมพิวเตอร์จะเรียนรู้จากประสบการณ์ E เกี่ยวกับงาน T และการวัดประสิทธิภาพ P หากประสิทธิภาพในงาน T ที่วัดด้วย P ดีขึ้นจากประสบการณ์ E"*

### ความแตกต่างระหว่าง Traditional Programming และ Machine Learning

#### Traditional Programming (การเขียนโปรแกรมแบบดั้งเดิม)
```
ข้อมูล + โปรแกรม → ผลลัพธ์
```
- โปรแกรมเมอร์เขียนกฎและคำสั่งที่ชัดเจน
- คอมพิวเตอร์ทำตามคำสั่งที่กำหนดไว้
- ไม่สามารถปรับตัวกับสถานการณ์ใหม่ได้

#### Machine Learning
```
ข้อมูล + ผลลัพธ์ที่ต้องการ → โมเดล (Model)
```
- ระบบเรียนรู้รูปแบบจากข้อมูล
- สร้างโมเดลที่สามารถทำนายผลลัพธ์ได้
- สามารถปรับตัวและปรับปรุงได้เมื่อมีข้อมูลใหม่

## 2.2 ประเภทของ Machine Learning

Machine Learning แบ่งออกเป็น 4 ประเภทหลัก:

### 2.2.1 Supervised Learning (การเรียนรู้แบบมีผู้สอน)

เป็นการเรียนรู้จากข้อมูลที่มีคำตอบที่ถูกต้องให้แล้ว (Labeled Data)

#### ลักษณะสำคัญ:
- มีข้อมูลตัวอย่าง (Training Data) ที่มีทั้ง Input และ Output
- เป้าหมายคือการสร้างโมเดลที่สามารถทำนาย Output จาก Input ใหม่ได้
- สามารถวัดความแม่นยำได้เพราะรู้คำตอบที่ถูกต้อง

#### แบ่งออกเป็น 2 ประเภทย่อย:

##### Classification (การจำแนกประเภท)
- **เป้าหมาย**: จำแนกข้อมูลเข้าสู่กลุ่มหรือประเภทที่กำหนดไว้
- **ตัวอย่างในการเกษตร**:
  - จำแนกว่าผลไม้สุกหรือยังไม่สุก
  - ตรวจจับโรคพืชจากภาพใบไม้
  - จำแนกชนิดของวัชพืช

##### Regression (การทำนายค่าต่อเนื่อง)
- **เป้าหมาย**: ทำนายค่าตัวเลขที่เป็นค่าต่อเนื่อง
- **ตัวอย่างในการเกษตร**:
  - ทำนายปริมาณผลผลิตข้าว (กิโลกรัม/ไร่)
  - คาดการณ์ราคาสินค้าเกษตร
  - ประมาณปริมาณน้ำที่ต้องใช้

### 2.2.2 Unsupervised Learning (การเรียนรู้แบบไม่มีผู้สอน)

เป็นการเรียนรู้จากข้อมูลที่ไม่มีคำตอบให้ (Unlabeled Data)

#### ลักษณะสำคัญ:
- มีเพียงข้อมูล Input เท่านั้น ไม่มี Output ที่ต้องการ
- เป้าหมายคือการค้นหารูปแบบหรือโครงสร้างที่ซ่อนอยู่ในข้อมูล
- ใช้สำหรับการสำรวจและทำความเข้าใจข้อมูล

#### ประเภทหลัก:

##### Clustering (การจัดกลุ่ม)
- **เป้าหมาย**: จัดกลุ่มข้อมูลที่มีลักษณะคล้ายกัน
- **ตัวอย่างในการเกษตร**:
  - จัดกลุ่มเกษตรกรตามพฤติกรรมการใช้ปุ่ย
  - แบ่งพื้นที่เกษตรตามลักษณะดิน
  - จัดกลุ่มลูกค้าตามการซื้อผลิตภัณฑ์เกษตร

##### Association Rules (การหาความสัมพันธ์)
- **เป้าหมาย**: ค้นหาความสัมพันธ์ระหว่างตัวแปรต่างๆ
- **ตัวอย่างในการเกษตร**:
  - "เกษตรกรที่ปลูกข้าวมักจะซื้อปุ่ยยูเรียด้วย"
  - "พื้นที่ที่มีความชื้นสูงมักจะมีปัญหาเชื้อรา"

### 2.2.3 Reinforcement Learning (การเรียนรู้เชิงเสริมแรง)

เป็นการเรียนรู้ผ่านการทดลองและผิดพลาด โดยได้รับรางวัลหรือการลงโทษ

#### ลักษณะสำคัญ:
- Agent (ตัวแทน) เรียนรู้จากการกระทำและผลที่ตามมา
- มีระบบรางวัล (Reward) และการลงโทษ (Penalty)
- เหมาะสำหรับปัญหาที่ต้องตัดสินใจต่อเนื่อง

#### ตัวอย่างในการเกษตร:
- หุ่นยนต์เก็บเกี่ยวที่เรียนรู้เส้นทางที่ดีที่สุด
- ระบบชลประทานที่ปรับการให้น้ำตามสภาพอากาศ
- โดรนที่เรียนรู้การบินเพื่อตรวจสอบพืชผล

### 2.2.4 Semi-Supervised Learning (การเรียนรู้แบบกึ่งมีผู้สอน)

เป็นการผสมผสานระหว่าง Supervised และ Unsupervised Learning

#### ลักษณะสำคัญ:
- ใช้ข้อมูลที่มี Label น้อย ร่วมกับข้อมูลที่ไม่มี Label จำนวนมาก
- เหมาะสำหรับสถานการณ์ที่การติด Label มีต้นทุนสูง
- ช่วยปรับปรุงประสิทธิภาพเมื่อข้อมูลที่มี Label มีจำกัด

## 2.3 อัลกอริทึม Machine Learning ที่สำคัญ

### 2.3.1 Linear Regression (การถดถอยเชิงเส้น)

เป็นอัลกอริทึมพื้นฐานสำหรับ Regression ที่หาความสัมพันธ์เชิงเส้นระหว่างตัวแปร

#### หลักการทำงาน:
- หาเส้นตรงที่ผ่านจุดข้อมูลได้ดีที่สุด
- ใช้สมการ: y = mx + b
- m = ความชัน, b = จุดตัดแกน y

#### ตัวอย่างการใช้งานในการเกษตร:
```python
# ตัวอย่าง: ทำนายผลผลิตข้าวจากปริมาณปุ่ย
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# ข้อมูลตัวอย่าง
fertilizer_amount = np.array([10, 20, 30, 40, 50, 60]).reshape(-1, 1)  # กก./ไร่
rice_yield = np.array([500, 650, 800, 900, 1000, 1100])  # กก./ไร่

# สร้างโมเดล
model = LinearRegression()
model.fit(fertilizer_amount, rice_yield)

# ทำนายผลผลิต
new_fertilizer = np.array([[35]])
predicted_yield = model.predict(new_fertilizer)
print(f"ปุ่ย 35 กก./ไร่ คาดว่าจะได้ผลผลิต {predicted_yield[0]:.0f} กก./ไร่")
```

### 2.3.2 Decision Tree (ต้นไม้ตัดสินใจ)

เป็นอัลกอริทึมที่สร้างกฎการตัดสินใจในรูปแบบต้นไม้

#### หลักการทำงาน:
- แบ่งข้อมูลตามคุณสมบัติที่ให้ข้อมูลมากที่สุด
- สร้างกฎ if-then ที่เข้าใจง่าย
- สามารถใช้ได้ทั้ง Classification และ Regression

#### ตัวอย่างการใช้งานในการเกษตร:
```
ตัดสินใจว่าควรรดน้ำหรือไม่?

ความชื้นดิน < 30%?
├─ ใช่: อุณหภูมิ > 35°C?
│   ├─ ใช่: รดน้ำมาก (3 ลิตร/ตร.ม.)
│   └─ ไม่: รดน้ำปานกลาง (2 ลิตร/ตร.ม.)
└─ ไม่: ไม่ต้องรดน้ำ
```

### 2.3.3 K-Means Clustering

เป็นอัลกอริทึม Unsupervised Learning สำหรับการจัดกลุ่มข้อมูล

#### หลักการทำงาน:
1. กำหนดจำนวนกลุ่ม (k) ที่ต้องการ
2. วางจุดศูนย์กลาง (centroid) แบบสุ่ม
3. จัดข้อมูลเข้ากลุ่มตามระยะทางที่ใกล้ที่สุด
4. คำนวณจุดศูนย์กลางใหม่
5. ทำซ้ำจนกว่าจะไม่เปลี่ยนแปลง

#### ตัวอย่างการใช้งานในการเกษตร:
```python
# ตัวอย่าง: จัดกลุ่มพื้นที่เกษตรตามลักษณะดิน
from sklearn.cluster import KMeans
import numpy as np

# ข้อมูลลักษณะดิน: [pH, ความชื้น, ไนโตรเจน]
soil_data = np.array([
    [6.5, 45, 20], [6.8, 50, 25], [7.0, 40, 18],
    [5.5, 60, 30], [5.8, 65, 35], [5.2, 70, 40],
    [8.0, 25, 10], [8.2, 30, 12], [7.8, 20, 8]
])

# จัดกลุ่มเป็น 3 กลุ่ม
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(soil_data)

print("กลุ่มของแต่ละพื้นที่:", clusters)
# ผลลัพธ์อาจเป็น: [0, 0, 0, 1, 1, 1, 2, 2, 2]
# กลุ่ม 0: ดินกลาง, กลุ่ม 1: ดินเปรียว, กลุ่ม 2: ดินด่าง
```

### 2.3.4 Support Vector Machine (SVM)

เป็นอัลกอริทึมที่หาเส้นแบ่ง (hyperplane) ที่ดีที่สุดระหว่างกลุ่มข้อมูล

#### หลักการทำงาน:
- หาเส้นแบ่งที่มีระยะห่างสูงสุดจากข้อมูลที่ใกล้ที่สุด
- ใช้ Support Vectors (จุดข้อมูลที่สำคัญ) ในการสร้างเส้นแบ่ง
- สามารถจัดการข้อมูลที่ซับซ้อนด้วย Kernel Trick

#### ตัวอย่างการใช้งานในการเกษตร:
- จำแนกโรคพืชจากภาพใบไม้
- แยกแยะวัชพืชจากพืชผล
- ตรวจจับคุณภาพผลไม้

## 2.4 กระบวนการ Machine Learning

### 2.4.1 ขั้นตอนการพัฒนาโมเดล ML

#### 1. การกำหนดปัญหา (Problem Definition)
- ระบุว่าเป็นปัญหาประเภทใด (Classification, Regression, Clustering)
- กำหนดเป้าหมายที่ชัดเจน
- เลือกตัวชี้วัดความสำเร็จ (Metrics)

#### 2. การรวบรวมข้อมูล (Data Collection)
- หาแหล่งข้อมูลที่เหมาะสม
- รวบรวมข้อมูลให้เพียงพอและหลากหลาย
- ตรวจสอบคุณภาพข้อมูล

#### 3. การเตรียมข้อมูล (Data Preparation)
- ทำความสะอาดข้อมูล (Data Cleaning)
- จัดการข้อมูลที่หายไป (Missing Data)
- แปลงข้อมูลให้อยู่ในรูปแบบที่เหมาะสม

#### 4. การสำรวจข้อมูล (Exploratory Data Analysis)
- วิเคราะห์ลักษณะของข้อมูล
- หาความสัมพันธ์ระหว่างตัวแปร
- ระบุข้อมูลผิดปกติ (Outliers)

#### 5. การเลือกและฝึกโมเดล (Model Selection & Training)
- เลือกอัลกอริทึมที่เหมาะสม
- แบ่งข้อมูลเป็น Training และ Testing Set
- ฝึกโมเดลด้วยข้อมูล Training

#### 6. การประเมินโมเดล (Model Evaluation)
- ทดสอบโมเดลด้วยข้อมูล Testing
- วัดประสิทธิภาพด้วย Metrics ที่เหมาะสม
- วิเคราะห์ข้อผิดพลาด

#### 7. การปรับปรุงโมเดล (Model Improvement)
- ปรับพารามิเตอร์ (Hyperparameter Tuning)
- ลองอัลกอริทึมอื่น
- เพิ่มหรือลดคุณสมบัติ (Feature Engineering)

#### 8. การนำไปใช้งาน (Deployment)
- นำโมเดลไปใช้ในสภาพแวดล้อมจริง
- ติดตามประสิทธิภาพ
- อัปเดตโมเดลเมื่อจำเป็น

### 2.4.2 การประเมินประสิทธิภาพ

#### สำหรับ Classification:
- **Accuracy**: ความแม่นยำโดยรวม
- **Precision**: ความแม่นยำของการทำนายเชิงบวก
- **Recall**: ความครบถ้วนของการทำนายเชิงบวก
- **F1-Score**: ค่าเฉลี่ยฮาร์โมนิกของ Precision และ Recall

#### สำหรับ Regression:
- **Mean Absolute Error (MAE)**: ค่าเฉลี่ยของความผิดพลาดสัมบูรณ์
- **Mean Squared Error (MSE)**: ค่าเฉลี่ยของความผิดพลาดยกกำลังสอง
- **Root Mean Squared Error (RMSE)**: รากที่สองของ MSE
- **R-squared**: สัดส่วนความแปรปรวนที่อธิบายได้

## 2.5 Machine Learning ในการเกษตร: กรณีศึกษาเชิงลึก

### 2.5.1 การทำนายผลผลิตข้าว

#### ปัญหา:
เกษตรกรต้องการทราบล่วงหน้าว่าจะได้ผลผลิตข้าวเท่าไหร่ เพื่อวางแผนการขายและการจัดการ

#### วิธีการแก้ไข:
ใช้ Regression Model ทำนายผลผลิตจากปัจจัยต่างๆ

#### ตัวแปรที่สำคัญ:
- ข้อมูลสภาพอากาศ: อุณหภูมิ, ปริมาณฝน, ความชื้น
- ข้อมูลดิน: pH, ไนโตรเจน, ฟอสฟอรัส, โพแทสเซียม
- การจัดการ: ปริมาณปุ่ย, การใช้ยาฆ่าแมลง, ความถี่ในการรดน้ำ
- พันธุ์ข้าว: ชนิดและลักษณะของพันธุ์

#### ตัวอย่างโค้ด:
```python
import pandas as pd
from sklearn.ensemble import RandomForestRegressor
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, r2_score

# สร้างข้อมูลตัวอย่าง
data = {
    'temperature': [28, 30, 32, 29, 31, 27, 33, 30, 28, 31],
    'rainfall': [120, 100, 80, 140, 90, 160, 70, 110, 130, 95],
    'humidity': [75, 70, 65, 80, 68, 85, 60, 72, 78, 69],
    'soil_ph': [6.5, 6.8, 7.0, 6.2, 6.9, 6.4, 7.2, 6.7, 6.3, 6.8],
    'nitrogen': [25, 30, 20, 35, 28, 22, 32, 26, 24, 29],
    'fertilizer': [40, 50, 35, 60, 45, 38, 55, 42, 39, 48],
    'yield': [850, 920, 780, 980, 860, 800, 950, 880, 820, 900]
}

df = pd.DataFrame(data)

# แบ่งข้อมูล
X = df.drop('yield', axis=1)
y = df['yield']
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# สร้างและฝึกโมเดล
model = RandomForestRegressor(n_estimators=100, random_state=42)
model.fit(X_train, y_train)

# ทำนายและประเมิน
y_pred = model.predict(X_test)
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

print(f"Mean Squared Error: {mse:.2f}")
print(f"R-squared Score: {r2:.2f}")

# ความสำคัญของตัวแปร
feature_importance = pd.DataFrame({
    'feature': X.columns,
    'importance': model.feature_importances_
}).sort_values('importance', ascending=False)

print("\nความสำคัญของตัวแปร:")
print(feature_importance)
```

### 2.5.2 การตรวจจับโรคพืชด้วยภาพ

#### ปัญหา:
การตรวจจับโรคพืชด้วยตาเปล่าต้องใช้ความเชี่ยวชาญและเวลามาก

#### วิธีการแก้ไข:
ใช้ Image Classification ด้วย Machine Learning

#### ขั้นตอนการทำงาน:
1. รวบรวมภาพใบไม้ที่สุขภาพดีและป่วย
2. ติด Label แต่ละภาพ
3. แยกคุณสมบัติจากภาพ (Feature Extraction)
4. ฝึกโมเดล Classification
5. ทดสอบและปรับปรุง

#### ตัวอย่างการแยกคุณสมบัติ:
```python
import cv2
import numpy as np
from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler

def extract_color_features(image_path):
    """แยกคุณสมบัติสีจากภาพใบไม้"""
    img = cv2.imread(image_path)
    img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    
    # คำนวณค่าเฉลี่ยสี RGB
    mean_rgb = np.mean(img.reshape(-1, 3), axis=0)
    
    # คำนวณค่าเบี่ยงเบนมาตรฐานสี
    std_rgb = np.std(img.reshape(-1, 3), axis=0)
    
    # แปลงเป็น HSV และคำนวณค่าเฉลี่ย
    hsv = cv2.cvtColor(img, cv2.COLOR_RGB2HSV)
    mean_hsv = np.mean(hsv.reshape(-1, 3), axis=0)
    
    # รวมคุณสมบัติทั้งหมด
    features = np.concatenate([mean_rgb, std_rgb, mean_hsv])
    return features

def extract_texture_features(image_path):
    """แยกคุณสมบัติเนื้อผิวจากภาพ"""
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    
    # คำนวณ Local Binary Pattern (LBP) แบบง่าย
    lbp = np.zeros_like(img)
    for i in range(1, img.shape[0]-1):
        for j in range(1, img.shape[1]-1):
            center = img[i, j]
            binary_string = ''
            # ตรวจสอบ 8 จุดรอบๆ
            neighbors = [
                img[i-1, j-1], img[i-1, j], img[i-1, j+1],
                img[i, j+1], img[i+1, j+1], img[i+1, j],
                img[i+1, j-1], img[i, j-1]
            ]
            for neighbor in neighbors:
                binary_string += '1' if neighbor >= center else '0'
            lbp[i, j] = int(binary_string, 2)
    
    # คำนวณ histogram ของ LBP
    hist, _ = np.histogram(lbp.flatten(), bins=256, range=(0, 256))
    return hist / np.sum(hist)  # Normalize
```

### 2.5.3 การจัดกลุ่มเกษตรกรเพื่อการให้คำแนะนำ

#### ปัญหา:
เกษตรกรแต่ละคนมีความต้องการและปัญหาที่แตกต่างกัน การให้คำแนะนำแบบเดียวกันทุกคนไม่มีประสิทธิภาพ

#### วิธีการแก้ไข:
ใช้ Clustering เพื่อจัดกลุ่มเกษตรกรตามลักษณะที่คล้ายกัน

#### ตัวแปรที่ใช้ในการจัดกลุ่ม:
- ขนาดพื้นที่เกษตร
- ชนิดพืชที่ปลูก
- ระดับการศึกษา
- อายุและประสบการณ์
- รายได้จากการเกษตร
- การใช้เทคโนโลยี

#### ตัวอย่างโค้ด:
```python
import pandas as pd
from sklearn.cluster import KMeans
from sklearn.preprocessing import StandardScaler
import matplotlib.pyplot as plt

# ข้อมูลเกษตรกร (ตัวอย่าง)
farmers_data = {
    'farm_size': [5, 15, 3, 25, 8, 12, 30, 6, 18, 4],
    'education_years': [6, 12, 4, 16, 8, 10, 14, 6, 12, 5],
    'age': [45, 35, 55, 40, 50, 38, 42, 48, 36, 52],
    'experience': [20, 10, 30, 15, 25, 12, 18, 22, 8, 28],
    'income': [150000, 400000, 80000, 800000, 200000, 300000, 900000, 120000, 450000, 90000],
    'tech_adoption': [2, 8, 1, 9, 4, 6, 10, 3, 7, 2]  # 1-10 scale
}

df = pd.DataFrame(farmers_data)

# ปรับมาตราส่วนข้อมูล
scaler = StandardScaler()
scaled_data = scaler.fit_transform(df)

# จัดกลุ่มด้วย K-Means
kmeans = KMeans(n_clusters=3, random_state=42)
clusters = kmeans.fit_predict(scaled_data)

# เพิ่มผลการจัดกลุ่มเข้าไปใน DataFrame
df['cluster'] = clusters

# วิเคราะห์ลักษณะของแต่ละกลุ่ม
cluster_summary = df.groupby('cluster').mean()
print("ลักษณะของแต่ละกลุ่มเกษตรกร:")
print(cluster_summary)

# การแปลผลและให้คำแนะนำ
recommendations = {
    0: "กลุ่มเกษตรกรรายย่อย: แนะนำเทคโนโลยีราคาถูก เน้นการเพิ่มประสิทธิภาพ",
    1: "กลุ่มเกษตรกรรายกลาง: แนะนำการใช้เทคโนโลยีสมัยใหม่ การจัดการแบบธุรกิจ",
    2: "กลุ่มเกษตรกรรายใหญ่: แนะนำระบบอัตโนมัติ AI และ IoT"
}

for cluster_id, recommendation in recommendations.items():
    print(f"\nกลุ่ม {cluster_id}: {recommendation}")
```

## 2.7 กิจกรรมและแบบฝึกหัด

### กิจกรรมที่ 1: การทดลอง Linear Regression

**วัตถุประสงค์**: ให้นักเรียนเข้าใจการทำงานของ Linear Regression

**อุปกรณ์**: คอมพิวเตอร์, Python, ข้อมูลการเกษตร

**ขั้นตอน**:
1. รวบรวมข้อมูลปริมาณปุ่ยและผลผลิตจากเกษตรกรในชุมชน
2. สร้างกราฟ Scatter Plot
3. หาเส้นแนวโน้มด้วย Linear Regression
4. ทำนายผลผลิตจากปริมาณปุ่ยที่กำหนด
5. วิเคราะห์ความแม่นยำของการทำนาย

### กิจกรรมที่ 2: การจำแนกคุณภาพผลไม้

**วัตถุประสงค์**: ให้นักเรียนเข้าใจ Classification

**อุปกรณ์**: ผลไม้ต่างๆ, ตาชั่ง, ไม้บรรทัด

**ขั้นตอน**:
1. วัดน้ำหนัก เส้นผ่านศูนย์กลาง และสีของผลไม้
2. จำแนกคุณภาพเป็น "ดี", "ปานกลาง", "ต่ำ"
3. สร้างโมเดล Decision Tree
4. ทดสอบการจำแนกกับผลไม้ชุดใหม่
5. ประเมินความแม่นยำ

### กิจกรรมที่ 3: การจัดกลุ่มพืชผล

**วัตถุประสงค์**: ให้นักเรียนเข้าใจ Clustering
