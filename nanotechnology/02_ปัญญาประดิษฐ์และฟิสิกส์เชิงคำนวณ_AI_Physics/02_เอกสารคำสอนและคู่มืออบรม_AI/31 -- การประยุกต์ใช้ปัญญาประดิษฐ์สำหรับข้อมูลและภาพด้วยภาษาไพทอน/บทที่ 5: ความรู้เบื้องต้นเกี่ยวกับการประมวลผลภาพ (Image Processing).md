## บทที่ 5: ความรู้เบื้องต้นเกี่ยวกับการประมวลผลภาพ (Image Processing)

ในส่วนที่ 3 ของหนังสือ เราจะเปลี่ยนจากการวิเคราะห์ข้อมูลในรูปแบบตาราง มาสู่การทำงานกับข้อมูลที่ไม่มีโครงสร้าง (Unstructured Data) ที่น่าสนใจและท้าทายยิ่งขึ้น นั่นคือ **รูปภาพ** ในบทนี้ เราจะปูพื้นฐานที่จำเป็นเกี่ยวกับการประมวลผลภาพ (Image Processing) ซึ่งเป็นความรู้พื้นฐานก่อนที่จะนำภาพไปใช้สร้างโมเดล Deep Learning ในบทถัดไป

### ภาพดิจิทัลคืออะไร: พิกเซลและช่องสี (Channels)

สำหรับคอมพิวเตอร์ รูปภาพไม่ได้เป็นอะไรมากไปกว่า **ตารางของตัวเลข** หรืออาร์เรย์ (Array) สองมิติ (สำหรับภาพขาว-ดำ) หรือสามมิติ (สำหรับภาพสี) จุดเล็กๆ แต่ละจุดที่ประกอบกันเป็นภาพเรียกว่า **พิกเซล (Pixel)** และค่าตัวเลขของแต่ละพิกเซลจะแสดงถึงความสว่างหรือสีของจุดนั้น

*   **ภาพขาว-ดำ (Grayscale Image):** เป็นอาร์เรย์ 2 มิติ (สูง x กว้าง) โดยแต่ละพิกเซลมีค่าเดียวที่แสดงระดับความสว่าง ตั้งแต่ 0 (สีดำสนิท) ไปจนถึง 255 (สีขาวสว่างสุด)

*   **ภาพสี (Color Image):** โดยทั่วไปจะใช้ระบบสี **RGB (Red, Green, Blue)** ซึ่งเป็นอาร์เรย์ 3 มิติ (สูง x กว้าง x ช่องสี) แต่ละพิกเซลจะประกอบด้วย 3 ค่า ที่แสดงความเข้มของแม่สีแดง, เขียว, และน้ำเงินตามลำดับ การผสมสีทั้งสามนี้ทำให้เกิดเป็นสีต่างๆ ที่เรามองเห็นได้

### การจัดการรูปภาพด้วยไลบรารี OpenCV และ Pillow

การจะแปลงรูปภาพให้เป็นอาร์เรย์ของตัวเลขเพื่อนำไปประมวลผลต่อใน Python นั้น เราต้องอาศัยไลบรารีเฉพาะทาง โดยสองไลบรารีที่ได้รับความนิยมสูงสุดคือ:

*   **OpenCV (Open Source Computer Vision Library):** เป็นไลบรารีที่ครอบคลุมและมีฟังก์ชันสำหรับการประมวลผลภาพและ Computer Vision ที่หลากหลายและมีประสิทธิภาพสูง เหมาะสำหรับงานที่ซับซ้อน
*   **Pillow (PIL Fork):** เป็นไลบรารีที่ใช้งานง่ายและเป็นมิตรกับผู้เริ่มต้น เหมาะสำหรับงานจัดการรูปภาพพื้นฐาน เช่น การเปิด, บันทึก, และปรับขนาด

ในหนังสือเล่มนี้ เราจะเน้นใช้ **OpenCV** เนื่องจากความสามารถที่หลากหลาย แต่หลักการทำงานจะคล้ายคลึงกัน

**การอ่านและแสดงผลรูปภาพด้วย OpenCV:**

```python
import cv2
import matplotlib.pyplot as plt

# อ่านรูปภาพจากไฟล์ (OpenCV จะอ่านเข้ามาเป็น BGR โดยดีฟอลต์)
img_bgr = cv2.imread('cat.jpg')

# แปลงจาก BGR เป็น RGB เพื่อให้ Matplotlib แสดงสีได้ถูกต้อง
img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)

# แสดงผลรูปภาพ
plt.imshow(img_rgb)
plt.title('My Cat')
plt.axis('off') # ปิดแกน X, Y
plt.show()

# ดูขนาดของอาร์เรย์ (สูง, กว้าง, ช่องสี)
print(img_rgb.shape)
```

### เทคนิคพื้นฐาน: การเปลี่ยนขนาด, การแปลงสี, การเบลอภาพ

ก่อนนำภาพไปใช้กับโมเดล เรามักจะต้องมีการประมวลผลเบื้องต้น (Preprocessing) ก่อนเสมอ เพื่อให้ภาพมีขนาดและรูปแบบที่เหมาะสม

**1. การเปลี่ยนขนาด (Resizing):** โมเดล Deep Learning ส่วนใหญ่มักต้องการภาพที่มีขนาดเท่ากันทั้งหมด เราจึงต้องปรับขนาดภาพให้เป็นไปตามที่โมเดลกำหนด

```python
# กำหนดขนาดใหม่เป็น 224x224 พิกเซล
new_size = (224, 224)
resized_img = cv2.resize(img_rgb, new_size)

plt.imshow(resized_img)
plt.title('Resized Image (224x224)')
plt.show()
```

**2. การแปลงเป็นภาพขาว-ดำ (Grayscale Conversion):** บางครั้งสีก็ไม่ใช่ข้อมูลที่จำเป็น และการลดมิติของภาพให้เหลือเพียง 1 channel จะช่วยให้โมเดลประมวลผลได้เร็วขึ้น

```python
gray_img = cv2.cvtColor(img_rgb, cv2.COLOR_RGB2GRAY)

plt.imshow(gray_img, cmap='gray') # cmap='gray' เพื่อให้แสดงผลเป็นภาพขาว-ดำ
plt.title('Grayscale Image')
plt.show()

print(gray_img.shape) # ผลลัพธ์จะเป็น (สูง, กว้าง) ไม่มีมิติของช่องสี
```

**3. การเบลอภาพ (Blurring):** เป็นเทคนิคที่ใช้เพื่อลดสัญญาณรบกวน (noise) ในภาพ ทำให้ภาพดูนุ่มนวลขึ้น ซึ่งอาจช่วยให้โมเดลจับลักษณะเด่นที่สำคัญได้ดีขึ้น

```python
# ใช้ Gaussian Blur
blurred_img = cv2.GaussianBlur(img_rgb, (15, 15), 0)

plt.imshow(blurred_img)
plt.title('Blurred Image')
plt.show()
```

การทำความเข้าใจพื้นฐานเหล่านี้เป็นสิ่งสำคัญอย่างยิ่ง เพราะมันคือขั้นตอนแรกในการเตรียมข้อมูลภาพให้พร้อมสำหรับ "สายตา" ของโมเดล Deep Learning ในบทต่อไป เราจะมาดูกันว่าโครงข่ายประสาทเทียมสามารถ "เรียนรู้" ที่จะมองเห็นและเข้าใจวัตถุในภาพเหล่านี้ได้อย่างไร
