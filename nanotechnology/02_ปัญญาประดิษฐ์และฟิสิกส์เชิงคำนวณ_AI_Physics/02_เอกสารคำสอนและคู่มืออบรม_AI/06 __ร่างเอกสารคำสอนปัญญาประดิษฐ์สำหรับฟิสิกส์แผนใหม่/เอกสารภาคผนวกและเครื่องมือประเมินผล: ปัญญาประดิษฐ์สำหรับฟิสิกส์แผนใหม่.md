### ปฏิบัติการที่ 1: Physics-Informed Neural Networks (PINNs) สำหรับสมการความร้อน 1 มิติ

* **วัตถุประสงค์:** ให้นักศึกษาสามารถสร้างโครงข่ายประสาทเทียมเพื่อแก้ปัญหาอนุพันธ์ย่อย (PDEs) โดยใช้ Physics Residual Loss แทนการใช้ข้อมูลทดลองจำนวนมาก
* **โจทย์ปัญหา:** จงหาฟังก์ชันอุณหภูมิ $u(x, t)$ ของแท่งวัตถวความยาว $L=1$ ระหว่างเวลา $t \in [0, 1]$ ซึ่งสอดคล้องกับสมการความร้อน $\frac{\partial u}{\partial t} = 0.01 \frac{\partial^2 u}{\partial x^2}$ โดยมีเงื่อนไขเริ่มต้น $u(x, 0) = \sin(\pi x)$ และเงื่อนไขขอบ $u(0, t) = u(1, t) = 0$

```python
import torch
import torch.nn as nn
import numpy as np

# กำหนดสถาปัตยกรรม PINN
class HeatPINN(nn.Module):
    def __init__(self):
        super(HeatPINN, self).__init__()
        self.net = nn.Sequential(
            nn.Linear(2, 32),
            nn.Tanh(),
            nn.Linear(32, 32),
            nn.Tanh(),
            nn.Linear(32, 1)
        )
    
    def forward(self, x, t):
        inputs = torch.cat([x, t], dim=1)
        return self.net(inputs)

# ฟังก์ชันคำนวณ Physics Residual
def compute_residual(model, x, t, alpha=0.01):
    x.requires_grad_(True)
    t.requires_grad_(True)
    u = model(x, t)
    
    u_t = torch.autograd.grad(u, t, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    u_x = torch.autograd.grad(u, x, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    u_xx = torch.autograd.grad(u_x, x, grad_outputs=torch.ones_like(u), create_graph=True)[0]
    
    residual = u_t - alpha * u_xx
    return torch.mean(residual**2)

print("Lab 1: PINN Heat Equation initialized successfully.")
```

### ปฏิบัติการที่ 2: Neural Network Quantum States (NQS) สำหรับระบบสปิน 1 มิติ

* **วัตถุประสงค์:** ให้นักศึกษาเข้าใจการใช้ Restricted Boltzmann Machines (RBM) เป็นฟังก์ชันคลื่นควอนตัมเพื่อหาพลังงานกราวด์สเตทของแบบจำลอง Ising
* **โจทย์ปัญหา:** คำนวณพลังงานกราวด์สเตทของ Transverse-Field Ising Model 1 มิติ จำนวน 10 สปิน โดยใช้ RBM และระเบียบวิธี Variational Monte Carlo (VMC)

```python
import torch
import torch.nn as nn

class QuantumRBM(nn.Module):
    def __init__(self, num_spins, num_hidden):
        super(QuantumRBM, self).__init__()
        self.visible_bias = nn.Parameter(torch.randn(num_spins))
        self.hidden_bias = nn.Parameter(torch.randn(num_hidden))
        self.weights = nn.Parameter(torch.randn(num_spins, num_hidden) * 0.1)
        
    def forward(self, s):
        # s shape: (batch_size, num_spins)
        v_term = torch.matmul(s, self.visible_bias)
        # log cosh hidden activation for Ising RBM wavefunction
        h_input = torch.matmul(s, self.weights) + self.hidden_bias
        h_term = torch.sum(torch.log(torch.cosh(h_input)), dim=1)
        return v_term + h_term

print("Lab 2: Quantum RBM Wavefunction initialized successfully.")
```

### ปฏิบัติการที่ 3: Sparse Identification of Nonlinear Dynamics (SINDy) สำหรับระบบพลวัต

* **วัตถุประสงค์:** ให้นักศึกษาสามารถสกัดสมการควบคุมทางกายภาพ (Governing Equations) ออกจากข้อมูลอนุกรมเวลาที่มีสัญญาณรบกวน
* **โจทย์ปัญหา:** กำหนดข้อมูลการแกว่งของระบบ non-linear oscillator จงใช้ Sparse Regression ค้นหาสมการเชิงอนุพันธ์ที่อธิบายระบบดังกล่าว

```python
import numpy as np

def generate_library(X, poly_order=2):
    n_samples, n_features = X.shape
    library = [np.ones((n_samples, 1))]
    
    # Linear terms
    library.append(X)
    
    # Quadratic terms
    if poly_order >= 2:
        for i in range(n_features):
            for j in range(i, n_features):
                library.append((X[:, i] * X[:, j]).reshape(-1, 1))
                
    return np.hstack(library)

print("Lab 3: SINDy Library Generator initialized successfully.")
```
