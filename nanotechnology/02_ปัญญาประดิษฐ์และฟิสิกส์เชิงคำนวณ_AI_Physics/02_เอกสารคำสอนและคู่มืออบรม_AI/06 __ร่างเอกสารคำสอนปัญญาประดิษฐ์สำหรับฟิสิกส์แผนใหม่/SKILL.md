# Academic Curriculum Generator

This skill provides a standardized workflow for generating rigorous academic curricula, teaching materials, exam papers, evaluation rubrics, and presentation scripts tailored for higher education and academic position evaluations (e.g., Associate Professor requests).

## Core Capabilities

1. **Curriculum Design & Syllabi**: 15-week syllabi complying with higher education standards (e.g., OHEC / ก.พ.อ. criteria) incorporating learning outcomes (CLOs) and Bloom's Taxonomy.
2. **Advanced Technical Content**: Deep theoretical framing integrated with programming examples (Python/PyTorch) and cutting-edge research topics (e.g., Physics-Informed AI, Quantum Machine Learning).
3. **Exams & Evaluation Rubrics**: Midterm and final exam questions with detailed step-by-step solutions, project evaluation forms, and oral defense rubrics.
4. **Academic Presentation Decks**: 10-slide presentation outlines with expanded 15-minute speaker notes for evaluation committees.

## Workflow

When tasked with creating academic curricula for rank advancement:
1. Establish course metadata (code, title, credits, level).
2. Define course learning outcomes (CLOs) aligned with educational taxonomies.
3. Construct a 15-week OHEC-compliant syllabus table.
4. Write core content chapters with mathematical formulations and code snippets.
5. Provide rigorous assessment tools (exams with solutions, rubrics, and research proposal outlines).
6. Generate structured presentation slides and 15-minute speaker scripts.
