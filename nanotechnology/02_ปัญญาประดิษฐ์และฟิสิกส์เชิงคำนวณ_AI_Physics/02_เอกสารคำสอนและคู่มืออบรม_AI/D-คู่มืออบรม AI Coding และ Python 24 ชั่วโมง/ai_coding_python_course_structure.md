# โครงสร้างหลักสูตรอบรมเชิงปฏิบัติการ 24 ชั่วโมง: AI Coding & Python (Basic to Advanced)

| โมดูล | หัวข้อ | ระยะเวลา (ชั่วโมง) | เนื้อหาหลัก |
| :--- | :--- | :--- | :--- |
| **1** | **Python Fundamentals for AI (พื้นฐาน Python สำหรับ AI)** | 4 | การติดตั้งสภาพแวดล้อม (Anaconda/VS Code), ไวยากรณ์ (Syntax), ชนิดข้อมูล (Data Types), ตัวดำเนินการ (Operators), โครงสร้างควบคุม (Control Flow), ฟังก์ชัน (Functions) |
| **2** | **Data Structures & Object-Oriented Programming (โครงสร้างข้อมูลและการเขียนโปรแกรมเชิงวัตถุ)** | 4 | โครงสร้างข้อมูลขั้นสูง (List, Tuple, Dictionary, Set), การจัดการไฟล์ (File I/O), แนวคิด OOP (Class, Object, Inheritance), การจัดการข้อผิดพลาด (Exception Handling) |
| **3** | **Python for Data Analysis (Python สำหรับการวิเคราะห์ข้อมูล)** | 4 | NumPy (การจัดการ Array), Pandas (DataFrames, การทำความสะอาดและจัดการข้อมูล), Matplotlib/Seaborn (การสร้างภาพข้อมูลเบื้องต้น) |
| **4** | **Machine Learning Fundamentals with Scikit-learn (พื้นฐาน Machine Learning ด้วย Scikit-learn)** | 4 | แนวคิด ML, การเตรียมข้อมูล (Preprocessing), การเรียนรู้แบบมีผู้สอน (Supervised Learning: Regression, Classification), การประเมินผลโมเดล (Model Evaluation) |
| **5** | **Introduction to Deep Learning (เบื้องต้น Deep Learning)** | 4 | โครงข่ายประสาทเทียม (Neural Networks), แนะนำ PyTorch/TensorFlow, การจำแนกภาพเบื้องต้น (เช่น MNIST) |
| **6** | **AI-Powered Coding & Project Deployment (การเขียนโค้ดด้วย AI และการนำโปรเจกต์ไปใช้งาน)** | 4 | การใช้ AI Assistant (เช่น แนวคิด GitHub Copilot) ในการสร้างโค้ด, การดีบัก, การทดสอบ. โครงสร้างโปรเจกต์, แนวคิดการนำไปใช้งานเบื้องต้น (เช่น FastAPI/Streamlit) |
