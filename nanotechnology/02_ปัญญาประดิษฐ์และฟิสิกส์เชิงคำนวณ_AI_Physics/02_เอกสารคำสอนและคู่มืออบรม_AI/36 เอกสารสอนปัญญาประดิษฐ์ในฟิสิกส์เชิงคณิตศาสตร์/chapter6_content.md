# บทที่ 6: การจำลองและการสร้างแบบจำลองด้วย AI (AI-driven Simulation and Modeling)

## วัตถุประสงค์
- เข้าใจสถาปัตยกรรมและหลักการทำงานของ Convolutional Neural Networks (CNNs)
- ประยุกต์ใช้ CNNs ในการวิเคราะห์ข้อมูลที่มีลักษณะเป็นโครงสร้างกริด เช่น ภาพถ่ายจากกล้องโทรทรรศน์หรือข้อมูลจากเครื่องตรวจจับอนุภาค
- เรียนรู้การประยุกต์ใช้ CNNs ในฟิสิกส์อนุภาคและดาราศาสตร์ รวมถึงการจำแนกเหตุการณ์และการวิเคราะห์โครงสร้างของวัสดุ

## 6.1 หลักการของการสังวัตนาการ (Convolution) และการรวมกลุ่ม (Pooling)

### การสังวัตนาการ (Convolution)
การสังวัตนาการเป็นหัวใจสำคัญของ CNNs โดยเป็นการดำเนินการทางคณิตศาสตร์ที่ใช้ตัวกรอง (filter หรือ kernel) ขนาดเล็กเลื่อนไปทั่วข้อมูลนำเข้า (input data) เพื่อสร้างแผนที่คุณลักษณะ (feature map) ที่เน้นคุณสมบัติเฉพาะ เช่น ขอบ, มุม หรือพื้นผิว

**สมการการสังวัตนาการ:**
สำหรับภาพ 2 มิติ $I$ และตัวกรอง $K$ การสังวัตนาการ $S(i, j)$ สามารถเขียนได้ดังนี้:
$$S(i, j) = (I * K)(i, j) = \sum_m \sum_n I(i-m, j-n) K(m, n)$$

**ตัวอย่าง:** การตรวจจับขอบในภาพถ่ายทางดาราศาสตร์เพื่อระบุขอบเขตของกาแล็กซี

### การรวมกลุ่ม (Pooling)
การรวมกลุ่ม (หรือ Subsampling) เป็นการลดขนาดของแผนที่คุณลักษณะ เพื่อลดจำนวนพารามิเตอร์และลดความซับซ้อนในการคำนวณ รวมถึงช่วยให้แบบจำลองมีความทนทานต่อการเปลี่ยนแปลงตำแหน่งเล็กน้อยของข้อมูลนำเข้า (translation invariance) ที่นิยมใช้คือ Max Pooling และ Average Pooling

**Max Pooling:** เลือกค่าสูงสุดจากแต่ละส่วนย่อยของแผนที่คุณลักษณะ
**Average Pooling:** คำนวณค่าเฉลี่ยจากแต่ละส่วนย่อยของแผนที่คุณลักษณะ

**ตัวอย่าง:** การลดขนาดข้อมูลภาพจากเครื่องตรวจจับอนุภาค เพื่อให้แบบจำลองสามารถประมวลผลได้เร็วขึ้นโดยไม่สูญเสียข้อมูลสำคัญ

## 6.2 สถาปัตยกรรมของ CNN: LeNet, AlexNet, VGG และ ResNet

CNNs มีสถาปัตยกรรมที่หลากหลาย ซึ่งแต่ละแบบมีจุดเด่นและเหมาะกับการใช้งานที่แตกต่างกัน

- **LeNet:** หนึ่งใน CNNs ยุคแรกๆ ที่ใช้สำหรับการรู้จำตัวเลขเขียนด้วยมือ มีโครงสร้างที่เรียบง่ายประกอบด้วยชั้น Convolutional และ Pooling สลับกัน
- **AlexNet:** เป็นจุดเริ่มต้นของ Deep Learning ที่ประสบความสำเร็จอย่างสูงในการแข่งขัน ImageNet ด้วยการใช้ GPU และเทคนิค Dropout
- **VGG:** เน้นการใช้ตัวกรองขนาดเล็ก (3x3) ซ้ำๆ กันหลายชั้น ทำให้มีโครงสร้างที่ลึกและมีประสิทธิภาพสูง
- **ResNet (Residual Network):** แนะนำแนวคิด Residual Connections (หรือ Skip Connections) เพื่อแก้ปัญหา Vanishing Gradient ในโครงข่ายที่ลึกมากๆ ทำให้สามารถสร้างโครงข่ายที่มีความลึกหลายร้อยชั้นได้

**ตัวอย่าง:** การใช้ ResNet ในการจำแนกประเภทของอนุภาคที่เกิดจากการชนกันในเครื่องเร่งอนุภาคขนาดใหญ่ (LHC)

## 6.3 การประยุกต์ใช้ในการวิเคราะห์ภาพจากกล้องโทรทรรศน์และเครื่องตรวจจับอนุภาค

CNNs มีบทบาทสำคัญในการวิเคราะห์ข้อมูลภาพในฟิสิกส์

- **ดาราศาสตร์:** การจำแนกประเภทของกาแล็กซี, การตรวจจับ Supernovae, การวิเคราะห์ภาพจากกล้องโทรทรรศน์อวกาศ (เช่น Hubble, James Webb)
- **ฟิสิกส์อนุภาค:** การวิเคราะห์ร่องรอยอนุภาคในเครื่องตรวจจับ, การจำแนกประเภทของอนุภาค (เช่น อิเล็กตรอน, มิวออน, เจ็ต), การค้นหาสัญญาณของอนุภาคใหม่

**ตัวอย่างงานวิจัย:** การใช้ CNNs เพื่อคัดแยกสัญญาณของอนุภาคฮิกส์โบซอนออกจากพื้นหลังในข้อมูลจาก LHC

## 6.4 การจำแนกเหตุการณ์ในฟิสิกส์อนุภาคพลังงานสูง (เช่น ที่ LHC)

ในฟิสิกส์อนุภาคพลังงานสูง การชนกันของอนุภาคจะสร้างข้อมูลจำนวนมหาศาล CNNs ถูกนำมาใช้เพื่อ:

- **จำแนกเหตุการณ์:** แยกแยะเหตุการณ์ที่น่าสนใจ (เช่น การสลายตัวของอนุภาคหายาก) ออกจากเหตุการณ์พื้นหลัง (background events) ที่เกิดขึ้นบ่อยครั้ง
- **ลดข้อมูล:** ช่วยลดปริมาณข้อมูลที่ต้องจัดเก็บและวิเคราะห์โดยการคัดกรองเหตุการณ์ที่ไม่เกี่ยวข้อง

**ตัวอย่างโค้ด:** การใช้ CNN เพื่อจำแนกประเภทของเหตุการณ์การชนกันของอนุภาค

```python
import numpy as np
import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, Dense

# สมมติข้อมูลภาพจากเครื่องตรวจจับอนุภาค (ขนาด 28x28 pixels, 1 ช่องสี)
# X_train: ภาพเหตุการณ์, y_train: ประเภทเหตุการณ์ (0: background, 1: signal)
(X_train, y_train), (X_test, y_test) = tf.keras.datasets.mnist.load_data() # ใช้ MNIST เป็นตัวอย่าง

# ปรับขนาดข้อมูลให้เข้ากับ CNN (เพิ่ม dimension สำหรับช่องสี)
X_train = X_train.reshape(X_train.shape[0], 28, 28, 1).astype('float32') / 255
X_test = X_test.reshape(X_test.shape[0], 28, 28, 1).astype('float32') / 255

# สร้างแบบจำลอง CNN
model = Sequential([
    Conv2D(32, (3, 3), activation='relu', input_shape=(28, 28, 1)),
    MaxPooling2D((2, 2)),
    Conv2D(64, (3, 3), activation='relu'),
    MaxPooling2D((2, 2)),
    Flatten(),
    Dense(128, activation='relu'),
    Dense(10, activation='softmax') # 10 classes for MNIST, adjust for physics events
])

# Compile และฝึกแบบจำลอง
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.fit(X_train, y_train, epochs=5, batch_size=64, validation_data=(X_test, y_test))

# ประเมินประสิทธิภาพ
loss, accuracy = model.evaluate(X_test, y_test)
print(f

"Test Accuracy: {accuracy:.4f}")
```

## 6.5 การใช้ CNN ในการวิเคราะห์โครงสร้างของวัสดุจากภาพจุลทรรศน์

CNNs สามารถนำมาใช้ในการวิเคราะห์ภาพจากกล้องจุลทรรศน์เพื่อศึกษาโครงสร้างระดับจุลภาคของวัสดุ เช่น การจำแนกประเภทของผลึก, การตรวจจับข้อบกพร่องในวัสดุ, หรือการวิเคราะห์ขนาดและรูปร่างของอนุภาคนาโน

**ตัวอย่าง:** การใช้ CNN เพื่อจำแนกโครงสร้างผลึกของวัสดุจากภาพ Electron Microscopy

## 6.6 Transfer Learning และการปรับแต่งแบบจำลองที่ฝึกสอนแล้ว

**Transfer Learning** เป็นเทคนิคที่ใช้แบบจำลอง CNN ที่ได้รับการฝึกฝนมาแล้วบนชุดข้อมูลขนาดใหญ่ (เช่น ImageNet) มาปรับใช้กับงานใหม่ที่มีข้อมูลจำกัดในโดเมนฟิสิกส์ เทคนิคนี้ช่วยลดเวลาและทรัพยากรในการฝึกฝนแบบจำลอง และมักให้ผลลัพธ์ที่ดีกว่าการฝึกฝนจากศูนย์

**ขั้นตอนหลัก:**
1. เลือกแบบจำลองที่ฝึกสอนแล้ว (Pre-trained Model) เช่น VGG, ResNet
2. ตัดส่วนหัว (Output Layer) ของแบบจำลองออก
3. เพิ่มชั้นใหม่ (Custom Layers) ที่เหมาะสมกับงานของเรา
4. ฝึกฝนเฉพาะชั้นใหม่ หรือปรับแต่ง (Fine-tune) บางส่วนของแบบจำลองเดิม

**ตัวอย่าง:** การใช้ Transfer Learning เพื่อจำแนกประเภทของซูเปอร์โนวาจากภาพถ่ายทางดาราศาสตร์ โดยใช้แบบจำลองที่ฝึกสอนแล้วบน ImageNet

## 6.7 การแสดงภาพและการตีความผลลัพธ์จาก CNN (Visualization และ Interpretability)

การทำความเข้าใจว่า CNN ตัดสินใจอย่างไรเป็นสิ่งสำคัญ โดยเฉพาะในงานวิจัยทางวิทยาศาสตร์ เทคนิคการแสดงภาพและตีความผลลัพธ์ช่วยให้เราสามารถ:

- **เห็นสิ่งที่ CNN มองเห็น:** เช่น Saliency Maps, Grad-CAM ที่แสดงส่วนของภาพที่แบบจำลองให้ความสำคัญ
- **เข้าใจคุณลักษณะที่เรียนรู้:** การวิเคราะห์ Feature Maps เพื่อดูว่าแต่ละชั้นของ CNN เรียนรู้คุณลักษณะใด

**ตัวอย่าง:** การใช้ Grad-CAM เพื่อระบุบริเวณในภาพการชนกันของอนุภาคที่ CNN ใช้ในการตัดสินใจว่ามีอนุภาคใหม่เกิดขึ้นหรือไม่

## ตัวอย่างงานวิจัย
- การใช้ CNNs เพื่อค้นหาสัญญาณของอนุภาคใหม่จากข้อมูลการชนกันของโปรตอนที่ Large Hadron Collider
- การวิเคราะห์ภาพจากกล้องโทรทรรศน์อวกาศเพื่อจำแนกประเภทของกาแล็กซีและศึกษาการกระจายตัวของสสารมืด

## บทสรุป
บทนี้ได้สำรวจหลักการและสถาปัตยกรรมของ Convolutional Neural Networks (CNNs) รวมถึงการประยุกต์ใช้ในงานฟิสิกส์อนุภาคและดาราศาสตร์ CNNs มีประสิทธิภาพสูงในการจัดการกับข้อมูลที่มีโครงสร้างเชิงพื้นที่ เช่น ภาพถ่าย และเป็นเครื่องมือสำคัญในการวิเคราะห์ข้อมูลขนาดใหญ่และการค้นพบทางวิทยาศาสตร์

## คำถามท้ายบท
1. อธิบายเหตุผลที่สถาปัตยกรรมของ CNN เหมาะสมกับการวิเคราะห์ข้อมูลรูปภาพในทางฟิสิกส์ และยกตัวอย่างการประยุกต์ใช้ 2 ตัวอย่าง
2. เปรียบเทียบข้อดีและข้อเสียของ Transfer Learning กับการฝึกสอนแบบจำลอง CNN ตั้งแต่เริ่มต้นในบริบทของการวิเคราะห์ข้อมูลฟิสิกส์ที่มีข้อมูลจำกัด
3. ออกแบบขั้นตอนการใช้ CNN ในการจำแนกประเภทของกาแล็กซีจากภาพดาราศาสตร์ โดยอธิบายถึงชั้นต่างๆ ที่จะใช้และเหตุผลในการเลือก
