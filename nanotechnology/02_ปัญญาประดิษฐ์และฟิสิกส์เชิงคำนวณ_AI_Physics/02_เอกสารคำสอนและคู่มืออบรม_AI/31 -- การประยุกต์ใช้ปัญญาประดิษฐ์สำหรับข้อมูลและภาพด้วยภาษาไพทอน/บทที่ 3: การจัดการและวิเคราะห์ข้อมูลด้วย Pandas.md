## บทที่ 3: การจัดการและวิเคราะห์ข้อมูลด้วย Pandas

เมื่อเรามีเครื่องมือพร้อมแล้ว ก็ถึงเวลาที่จะลงมือทำงานกับข้อมูลจริง ไลบรารีที่เราจะใช้เป็นเครื่องมือหลักในบทนี้คือ **Pandas** ซึ่งเป็นไลบรารีที่ทรงพลังที่สุดสำหรับการจัดการและวิเคราะห์ข้อมูลที่มีโครงสร้าง (Structured Data) ใน Python โดยโครงสร้างข้อมูลหลักที่ Pandas ใช้คือ **DataFrame**

### DataFrame: ตารางข้อมูลในโลกของ Python

ให้ลองนึกภาพ DataFrame เหมือนกับตารางในโปรแกรม Spreadsheet (เช่น Microsoft Excel) หรือตารางในฐานข้อมูล มันประกอบด้วยแถว (rows) และคอลัมน์ (columns) โดยแต่ละคอลัมน์สามารถมีชนิดข้อมูลที่แตกต่างกันได้ (เช่น ตัวเลข, ข้อความ, วันที่) ทำให้มันยืดหยุ่นและเหมาะสมกับข้อมูลในโลกความเป็นจริงอย่างยิ่ง

![Pandas DataFrame](https://pandas.pydata.org/docs/_images/01_table_dataframe.svg)
*ภาพที่ 3.1: โครงสร้างของ Pandas DataFrame (ที่มา: pandas.pydata.org)*

### การนำเข้าและส่งออกข้อมูล (CSV, Excel)

หนึ่งในความสามารถแรกๆ ที่เราต้องใช้คือการนำข้อมูลจากไฟล์ภายนอกเข้ามาในโปรแกรม Pandas รองรับไฟล์ข้อมูลหลากหลายรูปแบบ แตที่นิยมใช้กันมากที่สุดคือ CSV (Comma-Separated Values) และ Excel

**การอ่านไฟล์ CSV:**

สมมติว่าเรามีไฟล์ข้อมูลลูกค้าชื่อ `customers.csv` เราสามารถอ่านไฟล์นี้เข้ามาเป็น DataFrame ได้อย่างง่ายดายด้วยคำสั่ง `pd.read_csv()`

```python
import pandas as pd

# อ่านไฟล์ CSV เข้ามาเป็น DataFrame
df = pd.read_csv('customers.csv')

# แสดงผล 5 แถวแรกของ DataFrame เพื่อดูตัวอย่างข้อมูล
print(df.head())
```

**การอ่านไฟล์ Excel:**

การอ่านไฟล์ Excel ก็ทำได้ในลักษณะเดียวกัน โดยใช้ `pd.read_excel()` และสามารถระบุชื่อชีต (sheet) ที่ต้องการได้

```python
# อ่านข้อมูลจากชีตชื่อ 'Sheet1' ในไฟล์ Excel
df_excel = pd.read_excel('sales_data.xlsx', sheet_name='Sheet1')

print(df_excel.head())
```

### การสำรวจและทำความสะอาดข้อมูล (Data Cleaning)

ข้อมูลในโลกแห่งความเป็นจริงมักจะไม่สมบูรณ์แบบเสมอไป อาจมีข้อมูลที่ขาดหาย, ค่าที่ผิดพลาด, หรือรูปแบบที่ไม่สอดคล้องกัน ขั้นตอนนี้เรียกว่า **การทำความสะอาดข้อมูล (Data Cleaning)** ซึ่งเป็นขั้นตอนที่สำคัญและมักใช้เวลามากที่สุดในโปรเจกต์ Data Science

**คำสั่งพื้นฐานสำหรับการสำรวจข้อมูล:**

*   `df.head()`: ดูข้อมูล 5 แถวแรก
*   `df.tail()`: ดูข้อมูล 5 แถวสุดท้าย
*   `df.info()`: ดูสรุปข้อมูลโดยรวม เช่น จำนวนแถว, จำนวนคอลัมน์, และชนิดข้อมูลของแต่ละคอลัมน์
*   `df.describe()`: ดูค่าสถิติพื้นฐานของคอลัมน์ที่เป็นตัวเลข เช่น ค่าเฉลี่ย, ส่วนเบี่ยงเบนมาตรฐาน, ค่าสูงสุด, ค่าต่ำสุด

```python
# แสดงข้อมูลสรุปของ DataFrame
df.info()

# แสดงค่าสถิติของคอลัมน์ตัวเลข
print(df.describe())
```

### การจัดการข้อมูลที่ขาดหายไป (Missing Values)

ข้อมูลที่ขาดหายไป หรือที่เรียกว่าค่า `NaN` (Not a Number) เป็นปัญหาที่พบบ่อยมาก Pandas มีเครื่องมือที่ช่วยให้เราจัดการกับปัญหานี้ได้อย่างมีประสิทธิภาพ

**การตรวจสอบหาค่า NaN:**

เราสามารถใช้ `df.isnull().sum()` เพื่อนับจำนวนค่า `NaN` ในแต่ละคอลัมน์

```python
# นับจำนวนข้อมูลที่ขาดหายไปในแต่ละคอลัมน์
print(df.isnull().sum())
```

**วิธีการจัดการค่า NaN:**

1.  **การลบแถวหรือคอลัมน์ที่มีค่า NaN (Deletion):** เป็นวิธีที่ง่ายที่สุด แต่ก็เสี่ยงต่อการสูญเสียข้อมูลสำคัญหากมีค่า NaN จำนวนมาก
    ```python
    # ลบแถวที่มีค่า NaN อย่างน้อยหนึ่งค่า
    df_dropped = df.dropna()
    ```

2.  **การเติมค่าทดแทน (Imputation):** เป็นวิธีที่นิยมมากกว่า โดยเราจะเติมค่าที่เหมาะสมลงในช่องว่างนั้นๆ
    *   **เติมด้วยค่าคงที่:** เช่น 0, หรือ "Unknown"
    *   **เติมด้วยค่าทางสถิติ:** เช่น ค่าเฉลี่ย (mean) หรือค่ามัธยฐาน (median) ของคอลัมน์นั้นๆ

    ```python
    # เติมค่า NaN ในคอลัมน์ 'age' ด้วยค่าเฉลี่ยของอายุทั้งหมด
    mean_age = df['age'].mean()
    df['age'].fillna(mean_age, inplace=True)
    ```

ในบทนี้ เราได้เรียนรู้พื้นฐานการทำงานกับข้อมูลด้วย Pandas ตั้งแต่การนำเข้าข้อมูล, การสำรวจเบื้องต้น, ไปจนถึงการจัดการกับปัญหาข้อมูลที่พบบ่อยอย่างค่าที่ขาดหายไป ซึ่งทักษะเหล่านี้เป็นพื้นฐานที่จำเป็นอย่างยิ่งก่อนที่เราจะนำข้อมูลไปสร้างโมเดล Machine Learning ในบทต่อไป
