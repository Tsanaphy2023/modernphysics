## 2. รูปแบบไฟล์ข้อมูลทดลองจริง

ให้บันทึกเป็น CSV แบบ UTF-8 โดยมีอย่างน้อย 2 คอลัมน์ต่อไปนี้

| คอลัมน์ | ต้องมีหรือไม่ | คำอธิบาย |
|---|---|---|
| `group` | ต้องมี | ชื่อกลุ่ม เช่น `control`, `coating_A`, `coating_B` |
| `response` | ต้องมี | ค่าที่วัดได้เชิงตัวเลขหนึ่งค่าในแต่ละแถว |
| `sample_id` | แนะนำ | รหัสตัวอย่างเพื่อย้อนตรวจข้อมูล |
| `replicate` | แนะนำ | ลำดับหรือชนิดของการทำซ้ำ (technical/biological/measurement) |
| `unit` | แนะนำ | หน่วยของ response หรือบันทึกไว้ใน README |
| `batch` | แนะนำ | รอบการเตรียม/วัด เพื่อสังเกต batch effect |
| `time_min` | ตามกรณี | เวลาในการทดสอบ สำหรับข้อมูลแบบ time-series |
| `notes` | แนะนำ | เงื่อนไขหรือข้อสังเกตที่ช่วยตีความ เช่น dilution, instrument setting |

ตัวอย่าง **หัวตารางเท่านั้น** โดยไม่ใส่ข้อมูลสมมติ

```csv
sample_id,group,replicate,response,unit,batch,time_min,notes
```

### คำถามก่อนตีความกราฟ

1. จุดแต่ละจุดคือการทำซ้ำชนิดใด และเป็นอิสระต่อกันจริงหรือไม่
2. กลุ่ม control เหมาะสมกับคำถามหรือไม่
3. ขนาดผล (effect) มีความหมายเชิงวิทยาศาสตร์หรือเชิงการใช้งานมากเพียงใด ไม่ใช่เพียงต่างกันเชิงตัวเลขหรือไม่
4. ช่วงความเชื่อมั่นกว้างเพราะเหตุใด: `n` น้อย ความแปรปรวนสูง หรือขั้นตอนการวัดไม่คงที่
5. มี batch effect, outlier หรือข้อมูลขาดหายหรือไม่ และกลุ่มบันทึก/จัดการอย่างโปร่งใสแล้วหรือไม่

> ห้ามลบ outlier เพียงเพราะทำให้ค่าเฉลี่ย “ไม่สวย” ให้เก็บข้อมูลดิบไว้ทั้งหมด ระบุเกณฑ์การตรวจคุณภาพก่อนดูผล และรายงานการตัดสินใจทุกครั้ง

## 4. ทำ decision matrix แบบ value–risk–evidence

สร้างไฟล์ `decision_matrix.csv` ที่มีคอลัมน์บังคับต่อไปนี้

| คอลัมน์ | ความหมาย | ช่วงค่าที่ใช้ |
|---|---|---|
| `criterion` | เกณฑ์ย่อยที่ทีมต้องพิจารณา | ข้อความ |
| `dimension` | มิติของเกณฑ์ | `benefit`, `risk`, `safety`, `feasibility`, `equity`, `evidence` |
| `weight` | ความสำคัญสัมพัทธ์ของเกณฑ์ | 0 ขึ้นไป; script ปรับให้รวมเป็น 1 |
| `score` | การประเมินตามหลักฐานปัจจุบัน | 1–5; ต้องกำหนด anchor ของทีมก่อนให้คะแนน |
| `evidence_quality` | คุณภาพ/ความตรงของหลักฐาน | 1–5; 1 = อ่อน, 5 = แข็งแรงและตรงคำถาม |
| `uncertainty` | ระดับความไม่แน่นอน | 1–5; 1 = ต่ำ, 5 = สูง |
| `rationale` | เหตุผลและแหล่งข้อมูล | แนะนำอย่างยิ่ง |

ตัวอย่างหัวตารางเท่านั้น

```csv
criterion,dimension,weight,score,evidence_quality,uncertainty,rationale
```

รันโค้ดด้วยคำสั่ง

```python
!python data_lab_บทที่7_วิเคราะห์ข้อมูล.py decision \
  --input decision_matrix.csv \
  --output results_decision
```

ผลลัพธ์สำคัญคือ `03_evidence_uncertainty_map.png` ซึ่งทำให้เห็นว่าเกณฑ์ใดมีน้ำหนักมาก แต่ฐานหลักฐานยังอ่อนหรือมีความไม่แน่นอนสูง กลุ่มต้องใช้รูปนี้เพื่อระบุ **คำถามหรือข้อมูลที่ควรเก็บเพิ่ม** ไม่ใช่ใช้คะแนนรวมเป็นคำตอบอัตโนมัติ

## 5. แนวทางเขียน caption ของกราฟ

> **รูปที่ 1.** การเปรียบเทียบค่า `[response]` ของกลุ่ม `[control]` และ `[treatment]` ภายใต้เงื่อนไข `[ระบุเงื่อนไข]` จุดแสดงค่าการทำซ้ำแต่ละครั้ง รูปสี่เหลี่ยมแสดงค่าเฉลี่ย และเส้นแสดงช่วงความเชื่อมั่น 95% แบบ normal approximation; `n = …` ต่อกลุ่ม ข้อมูลนี้สนับสนุน/ยังไม่เพียงพอที่จะสนับสนุนข้อสรุปว่า `[claim แบบมีเงื่อนไข]` เนื่องจาก `[ข้อจำกัดสำคัญ]`.

## 6. เกณฑ์ตรวจงานก่อนส่ง
