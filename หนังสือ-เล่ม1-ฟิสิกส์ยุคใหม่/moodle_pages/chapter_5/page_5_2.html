5.2 เลขควอนตัมและสถานะของอิเล็กตรอน

เลขควอนตัมทั้ง 4 ตัว และรูปร่างออร์บิทัลเชิงควอนตัม s, p, d, f

🔢 เลขควอนตัม 4 ตัวที่ระบุสถานะอิเล็กตรอน

1. เลขควอนตัมหลัก (n)

Principal: n = 1, 2, 3, ... กำหนดระดับชั้นพลังงานหลักและขนาดออร์บิทัล

2. เลขควอนตัมโมเมนตัมเชิงมุม (l)

Orbital: l = 0 ถึง n-1 กำหนดรูปร่างออร์บิทัล (l=0: s, l=1: p, l=2: d, l=3: f)

3. เลขควอนตัมแม่เหล็ก (ml)

Magnetic: ml = -l ถึง +l กำหนดทิศทางการวางตัวในอวกาศ

4. เลขควอนตัมสปิน (ms)

Spin: ms = +1/2 (Spin-up) หรือ -1/2 (Spin-down)

📐 ตัวอย่างการนับสถานะ: ระดับชั้นพลังงาน n=3

WORKED EXAMPLE
โจทย์ตัวอย่าง: ในชั้นพลังงาน n=3 มีจำนวนออร์บิทัลย่อยและจำนวนอิเล็กตรอนได้สูงสุดกี่ตัว?
📝 เฉลยและขั้นตอนการคำนวณอย่างละเอียด:
1) l = 0 (1 ช่อง), l = 1 (3 ช่อง), l = 2 (5 ช่อง) รวมมี 9 ออร์บิทัล (n^2 = 9)
2) แต่ละออร์บิทัลจุได้ 2 ตัว รวมจุได้สูงสุด 2n^2 = 18 อิเล็กตรอน

💡 คำถามทบทวนแนวคิด (Concept Check)

คำถาม: ชุดเลขควอนตัม (n, l, ml, ms) ในข้อใดต่อไปนี้เป็นไปไม่ได้ตามกฎกลศาสตร์ควอนตัม?

  • A. (2, 1, 0, +1/2)
  • B. (3, 2, -2, -1/2)
  • C. (2, 2, 1, +1/2)
  • D. (1, 0, 0, -1/2)
เฉลยและคำอธิบายละเอียด (คลิกเพื่อดู)
คำตอบที่ถูกต้อง: ข้อ C.
ถูกต้อง! เพราะเมื่อ n=2 ค่า l สูงสุดคือ n-1 = 1 ดังนั้น l=2 จึงเป็นไปไม่ได้
