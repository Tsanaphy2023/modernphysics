## บทที่ 7: โครงการจริง: การสร้างแอปพลิเคชันจำแนกวัตถุในภาพ

ในบทสุดท้ายนี้ เราจะนำความรู้ทั้งหมดที่ได้เรียนมาตั้งแต่บทที่ 1 ถึง 6 มาประกอบกันเป็นโปรเจกต์ที่สมบูรณ์ นั่นคือการสร้างโมเดลสำหรับจำแนกประเภทรูปภาพตั้งแต่ต้นจนจบ โดยใช้โมเดล CNN ที่เราออกแบบไว้ในบทที่แล้วกับชุดข้อมูล CIFAR-10

### 1. การรวบรวมและเตรียมชุดข้อมูลรูปภาพ

โชคดีที่เราไม่ต้องไปรวบรวมรูปภาพด้วยตัวเอง Keras ได้เตรียมชุดข้อมูลยอดนิยมต่างๆ ไว้ให้เราเรียกใช้งานได้โดยตรง ซึ่งรวมถึง CIFAR-10 ด้วย

**การโหลดและเตรียมข้อมูล:**

ข้อมูลพิกเซลของรูปภาพมีค่าตั้งแต่ 0-255 แต่การทำให้ข้อมูลมีสเกลใกล้เคียงกัน (เช่น ระหว่าง 0-1) จะช่วยให้โมเดลเรียนรู้ได้ดีและเร็วขึ้น เราจึงจะนำค่าพิกเซลทั้งหมดมาหารด้วย 255.0

```python
import tensorflow as tf

# โหลดชุดข้อมูล CIFAR-10
(train_images, train_labels), (test_images, test_labels) = tf.keras.datasets.cifar10.load_data()

# ทำ Normalization ข้อมูลภาพให้อยู่ในช่วง 0-1
train_images, test_images = train_images / 255.0, test_images / 255.0

# กำหนดชื่อคลาสทั้ง 10 ประเภท
class_names = ["airplane", "automobile", "bird", "cat", "deer",
               "dog", "frog", "horse", "ship", "truck"]
```

### 2. การฝึกสอน (Training) โมเดล CNN

ตอนนี้เรามีทั้งโมเดลที่คอมไพล์แล้ว (จากบทที่ 6) และข้อมูลที่เตรียมพร้อมแล้ว ขั้นตอนต่อไปคือการส่งข้อมูลเข้าไป "ฝึก" โมเดลด้วยเมธอด `model.fit()`

**การฝึกสอนโมเดล:**

เราจะทำการฝึกโมเดลเป็นจำนวน 10 รอบ (epochs) ในแต่ละรอบ โมเดลจะพยายามปรับปรุงน้ำหนัก (weights) ภายในเพื่อลดค่าความผิดพลาด (loss) และเพิ่มความแม่นยำ (accuracy)

```python
# สมมติว่า 'model' คือโมเดลที่เราสร้างและคอมไพล์จากบทที่ 6

# เริ่มทำการฝึกสอนโมเดล
history = model.fit(train_images, train_labels, epochs=10, 
                    validation_data=(test_images, test_labels))
```

ระหว่างการฝึกสอน เราจะเห็นผลลัพธ์ของแต่ละ epoch แสดงขึ้นมา ซึ่งจะบอกค่า loss และ accuracy ทั้งของ training data และ validation data การสังเกตค่าเหล่านี้จะช่วยให้เราทราบว่าโมเดลกำลังเรียนรู้ได้ดีหรือไม่

**การประเมินผลหลังการฝึกสอน:**

หลังจากฝึกเสร็จ เราสามารถพล็อตกราฟเพื่อดูแนวโน้มของ accuracy และ loss ตลอดการฝึกได้

```python
import matplotlib.pyplot as plt

plt.plot(history.history["accuracy"], label="accuracy")
plt.plot(history.history["val_accuracy"], label="val_accuracy")
plt.xlabel("Epoch")
plt.ylabel("Accuracy")
plt.legend()
plt.show()
```

### 3. การทดสอบและนำโมเดลไปใช้งานจริง

หัวใจสำคัญของการสร้างโมเดลคือการนำไปใช้งานกับข้อมูลใหม่ที่ไม่เคยเห็นมาก่อน (unseen data) เราสามารถใช้เมธอด `model.predict()` เพื่อทำนายผลลัพธ์จากรูปภาพใหม่ๆ ได้

**การทำนายผล:**

```python
import numpy as np

# เลือกรูปภาพจาก test set มาทดสอบ (เช่น รูปที่ 10)
img_to_predict = test_images[10]

# โมเดลคาดหวัง input ที่มี 4 มิติ (batch_size, height, width, channels)
# เราจึงต้องเพิ่มมิติเข้าไปด้วย np.expand_dims
img_batch = np.expand_dims(img_to_predict, 0)

# ทำการทำนาย
predictions = model.predict(img_batch)

# ผลลัพธ์คืออาร์เรย์ของความน่าจะเป็นในแต่ละคลาส (Logits)
# เราใช้ np.argmax เพื่อหาคลาสที่มีความน่าจะเป็นสูงสุด
predicted_class_index = np.argmax(predictions[0])
predicted_class_name = class_names[predicted_class_index]

# แสดงผลการทำนาย
plt.imshow(img_to_predict)
plt.title(f"Predicted: {predicted_class_name}")
plt.axis("off")
plt.show()
```

เพียงเท่านี้ เราก็ได้สร้างแอปพลิเคชัน AI สำหรับจำแนกวัตถุในภาพตั้งแต่ต้นจนจบ ตั้งแต่การเตรียมข้อมูล, สร้างโมเดล, ฝึกสอน, และนำไปทดสอบใช้งานจริง โปรเจกต์นี้เป็นเพียงจุดเริ่มต้นเล็กๆ ที่แสดงให้เห็นถึงศักยภาพอันมหาศาลของ Deep Learning ซึ่งคุณสามารถนำความรู้และเทคนิคเหล่านี้ไปต่อยอดเพื่อสร้างสรรค์โปรเจกต์ที่ซับซ้อนและน่าทึ่งยิ่งขึ้นไปได้ในอนาคต
