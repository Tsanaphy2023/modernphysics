# Modern AI & Python Curriculum Structure

This reference defines the standard 6-module structure for a 24-hour "Basic to Advanced" workshop.

## Module 1: Python Fundamentals for Modern AI (4 Hours)
- **Focus**: Environment setup, syntax, and AI-driven development basics.
- **Key Topics**:
    - Setting up Cursor/VS Code with AI extensions.
    - Python 3.11+ features (Type Hinting, f-strings).
    - Basic Data Types & Control Flow.
    - Introduction to AI Coding Assistants (Prompt Engineering for Code).

## Module 2: Data Structures & OOP for Modern AI (4 Hours)
- **Focus**: Efficient data handling and modular code design.
- **Key Topics**:
    - Advanced Collections (`defaultdict`, `Counter`).
    - `dataclasses` for AI Model Configuration.
    - OOP Pillars: Encapsulation, Inheritance, Polymorphism.
    - Decorators for Logging and Performance Timing.
    - Context Managers for Resource Management (GPU/Memory).

## Module 3: Python for Data Analysis (4 Hours)
- **Focus**: Data manipulation and visualization for AI/ML.
- **Key Topics**:
    - NumPy: Vectorization and Broadcasting.
    - Pandas: Advanced Data Cleaning, GroupBy, and Pivot Tables.
    - Visualization: Matplotlib & Seaborn (Univariate/Bivariate Analysis).
    - Exploratory Data Analysis (EDA) for Machine Learning.

## Module 4: Machine Learning with Scikit-learn (4 Hours)
- **Focus**: Traditional ML workflows and model evaluation.
- **Key Topics**:
    - The ML Workflow: Preprocessing, Training, Evaluation.
    - Classification & Regression Algorithms.
    - Evaluation Metrics: Precision, Recall, F1, RMSE, R-squared.
    - Model Selection: Cross-Validation & Hyperparameter Tuning (GridSearch).

## Module 5: Deep Learning with PyTorch (4 Hours)
- **Focus**: Neural networks and modern deep learning frameworks.
- **Key Topics**:
    - Tensors and Autograd (Automatic Differentiation).
    - Building Neural Networks with `nn.Module`.
    - The Standard Training Loop (Forward/Backward Pass).
    - Introduction to CNNs and Transfer Learning.

## Module 6: Deployment & AI Coding Assistant (4 Hours)
- **Focus**: Productionizing AI models and advanced AI-driven development.
- **Key Topics**:
    - Building APIs with FastAPI.
    - Creating Interactive Dashboards with Streamlit.
    - Containerization with Docker.
    - Advanced AI Coding: Agentic Workflows and Refactoring.
    - Final Project Integration.
