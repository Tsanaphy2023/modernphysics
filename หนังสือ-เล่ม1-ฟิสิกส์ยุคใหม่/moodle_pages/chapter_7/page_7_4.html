7.4 ควาร์ก เลปตอน และกฎการอนุรักษ์

การสร้างบาริออนและมีซอน กฎการอนุรักษ์ประจุ เลขบาริออน เลขเลปตอน และสเตรนจ์เนสส์

🧩 ฮาดรอน (Hadrons): บาริออนและมีซอน

📌 ตระกูลฮาดรอน (อนุภาคที่ประกอบด้วยควาร์ก)โครงสร้างฮาดรอน
  • บาริออน (Baryons: 3 ควาร์ก): เลขบาริออน B = 1 เช่น โปรตอน (uud), นิวตรอน (udd)
  • มีซอน (Mesons: ควาร์ก + ปฏิควาร์ก): เลขบาริออน B = 0 เช่น ไพออน, เคออน
📌 กฎการอนุรักษ์ในการสลายตัวของอนุภาคConservation Laws

ปฏิกิริยานิวเคลียร์และอนุภาคต้องอนุรักษ์: พลังงาน-โมเมนตัม, ประจุไฟฟ้า, เลขบาริออน, และเลขเลปตอน

📐 ตัวอย่างการตรวจสอบ: การสลายตัวของนิวตรอน (Beta Decay)

โจทย์: ตรวจสอบปฏิกิริยา n -> p + e- + anti-nu ว่าสอดคล้องกับกฎการอนุรักษ์หรือไม่

เฉลยและวิธีทำ:
1) ประจุไฟฟ้า: 0 = (+1) + (-1) + 0 = 0 (อนุรักษ์)
2) เลขบาริออน: 1 = 1 + 0 + 0 = 1 (อนุรักษ์)
3) เลขเลปตอน: 0 = 0 + (+1) + (-1) = 0 (อนุรักษ์)

💡 คำถามทบทวนแนวคิด (Concept Check)

คำถาม: อนุภาคมีซอน (Meson) ประกอบด้วยโครงสร้างควาร์กแบบใด?

  • A. 3 ควาร์ก
  • B. 1 ควาร์ก และ 1 ปฏิควาร์ก
  • C. 2 เลปตอน
  • D. กลูออนล้วนๆ
เฉลยและคำอธิบายละเอียด (คลิกเพื่อดู)
คำตอบที่ถูกต้อง: ข้อ B.
ถูกต้อง! มีซอนมีสปินเป็นจำนวนเต็ม ประกอบด้วยคู่ควาร์ก-ปฏิควาร์กเสมอ
