## 1.1 บริบททางประวัติศาสตร์และเป้าหมายของฟิสิกส์เชิงคำนวณ

ฟิสิกส์เชิงคำนวณ (Computational Physics) ได้ก้าวขึ้นเป็นเสาหลักที่สามของการค้นคว้าทางวิทยาศาสตร์ ควบคู่ไปกับฟิสิกส์ทฤษฎี (Theoretical Physics) และฟิสิกส์ทดลอง (Experimental Physics) ในอดีต นักฟิสิกส์ต้องพึ่งพาสมการวิเคราะห์เชิงวิเคราะห์ (Analytical Solutions) ซึ่งจำกัดอยู่เพียงระบบอุดมคติที่มีความสมมาตรสูงหรือมีความเป็นเชิงเส้น (Linear Systems) แต่ในความเป็นจริง ปรากฏการณ์ธรรมชาติส่วนใหญ่มีความซับซ้อน ไม่เป็นเชิงเส้น (Nonlinear) และเกี่ยวข้องกับปฏิสัมพันธ์หลายอนุภาค (Many-Body Interactions) ซึ่งไม่สามารถหาคำตอบที่แท้จริงได้ด้วยมือ [1]

การถือกำเนิดขึ้นของคอมพิวเตอร์ดิจิทัลและการพัฒนาอัลกอริทึมเชิงตัวเลขในช่วงกลางศตวรรษที่ 20 ได้เปลี่ยนแปลงกระบวนทัศน์นี้อย่างถอนรากถอนโคน ฟิสิกส์เชิงคำนวณช่วยให้นักวิจัยสามารถจำลองสถานการณ์ทางกายภาพตั้งแต่ระดับอนุภาคควอนตัมไปจนถึงโครงสร้างขนาดใหญ่ระดับจักรวาล เช่น พลวัตของกาแล็กซี ปรากฏการณ์เทอร์โมไดนามิกส์ของสสารควอนตัม และพลวัตของของไหลซับซ้อน [2] เป้าหมายหลักของฟิสิกส์เชิงคำนวณจึงไม่ใช่เพียงแค่การคำนวณตัวเลข แต่เป็นการสร้างความเข้าใจเชิงลึกผ่านการจำลองแบบจำลองทางคณิตศาสตร์ที่สอดคล้องกับกฎเกณฑ์ทางกายภาพ

## 1.2 ความผิดพลาดทางตัวเลข การวิเคราะห์ความเสถียร และความแม่นยำ

การคำนวณด้วยคอมพิวเตอร์ดิจิทัลต้องเผชิญกับข้อจำกัดทางกายภาพของการแทนที่จำนวนจริงด้วยระบบเลขฐานสองที่มีจำนวนบิตจำกัด (Finite Precision Arithmetic) ตามมาตรฐาน IEEE 754 ซึ่งทำให้เกิดความผิดพลาดสำคัญ 2 ประการ ได้แก่ ความผิดพลาดจากการตัดทอน (Truncation Error) และความผิดพลาดจากการปัดเศษ (Roundoff Error) [3]

### ความผิดพลาดจากการตัดทอน
เกิดขึ้นจากการประมาณค่าทางคณิตศาสตร์ เช่น การแปลงอนุกรมอนันต์ให้เป็นอนุกรมจำกัดผ่านอนุกรมเทย์เลอร์ (Taylor Series Expansion):

$$f(x+h) = f(x) + hf'(x) + \frac{h^2}{2!}f''(x) + \frac{h^3}{3!}f'''(\xi)$$

เมื่อเราตัดพจน์ตั้งแต่กำลังสามขึ้นไปเพื่อประมาณค่าอนุพันธ์อันดับหนึ่ง

$$f'(x) \approx \frac{f(x+h) - f(x)}{h} - \frac{h}{2}f''(\xi)$$

ความผิดพลาดจากการตัดทอนนี้จะมีสัดส่วนแปรผันตรงกับขนาดของก้าว (Step Size, $h$) นั่นคือ $O(h)$

### ความผิดพลาดจากการปัดเศษ
เกิดขึ้นเนื่องจากความจำกัดของหน่วยความจำในการเก็บตัวเลขทศนิยม (เช่น ความแม่นยำระดับ Double Precision ที่มีความละเอียดประมาณ $\epsilon \approx 2.22 \times 10^{-16}$) เมื่อนำตัวเลขที่มีความแตกต่างกันมากๆ มาลบกัน จะเกิดการสูญเสียความแม่นยำที่มีนัยสำคัญ (Catastrophic Cancellation)

## 1.3 รากฐานทางคณิตศาสตร์สำหรับการคำนวณเชิงเมทริกซ์และพีชคณิตเชิงเส้น

ในระบบฟิสิกส์เชิงคำนวณ ปัญหาจำนวนมากสามารถลดรูปให้อยู่ในรูปสมการเมทริกซ์เชิงเส้น

$$A \mathbf{x} = \mathbf{b}$$

เมื่อ $A$ คือเมทริกซ์สัมประสิทธิ์ขนาด $N \times N$, $\mathbf{x}$ คือเวกเตอร์ตัวแปร และ $\mathbf{b}$ คือเวกเตอร์แหล่งกำเนิด การแก้ปัญหาระบบสมการเหล่านี้แบ่งออกเป็น 2 แนวทางหลัก ได้แก่ วิธีทางตรง (Direct Methods) เช่น การกำจัดเกาส์เซียน (Gaussian Elimination) และการแยกตัวประกอบ LU (LU Decomposition) ซึ่งเหมาะกับเมทริกซ์ขนาดเล็กถึงปานกลาง และวิธีเชิงวนซ้ำ (Iterative Methods) เช่น วิธีของจาคอบี (Jacobi Method) วิธีของเกาส์-ไซเดล (Gauss-Seidel Method) และวิธีคอนจูเกตเกรเดียนต์ (Conjugate Gradient Method) ซึ่งมีประสิทธิภาพสูงมากสำหรับเมทริกซ์เบาบาง (Sparse Matrices) ที่พบได้บ่อยในการแก้สมการอนุพันธ์ย่อย

## 1.4 ตัวอย่างการคำนวณอย่างละเอียด

**โจทย์ปัญหา** จงประมาณค่าอนุพันธ์อันดับหนึ่งของฟังก์ชัน $f(x) = \sin(x)$ ที่จุด $x = 1.0$ โดยใช้วิธีผลต่างไปข้างหน้า (Forward Difference) และวิธีผลต่างกึ่งกลาง (Central Difference) พร้อมทั้งคำนวณหาค่าความผิดพลาดสัมพัทธ์ (Relative Error) เมื่อกำหนดให้ค่าที่แท้จริงคือ $\cos(1.0) \approx 0.540302305868$

**วิธีทำ**
1. สูตรผลต่างไปข้างหน้า
   $$f'(x) \approx \frac{\sin(x+h) - \sin(x)}{h}$$
2. สูตรผลต่างกึ่งกลาง
   $$f'(x) \approx \frac{\sin(x+h) - \sin(x-h)}{2h}$$

เมื่อทดลองคำนวณด้วยขนาดก้าว $h = 0.01$:
- วิธีผลต่างไปข้างหน้าให้ค่าประมาณ $0.5358267$ (ความผิดพลาดสัมพัทธ์ $\approx 0.83\%$)
- วิธีผลต่างกึ่งกลางให้ค่าประมาณ $0.5403012$ (ความผิดพลาดสัมพัทธ์ $\approx 0.0002\%$)

ผลลัพธ์นี้แสดงให้เห็นอย่างชัดเจนว่าวิธีผลต่างกึ่งกลางมีความแม่นยำสูงกว่าอย่างมีนัยสำคัญ เนื่องจากมีความผิดพลาดจากการตัดทอนอยู่ในระดับ $O(h^2)$ ในขณะที่วิธีผลต่างไปข้างหน้าอยู่ในระดับ $O(h)$ [4]

## 1.5 ห้องปฏิบัติการเชิงคำนวณ การจำลองสมการคลื่น 1 มิติ

ในห้องปฏิบัติการนี้ เราจะพัฒนาโปรแกรมภาษา Python เพื่อจำลองการแพร่ของคลื่นบนเส้นลวดตึง (1D Wave Equation) ซึ่งอธิบายด้วยสมการอนุพันธ์ย่อยอันดับสอง

$$\frac{\partial^2 u}{\partial t^2} = v^2 \frac{\partial^2 u}{\partial x^2}$$

โดยใช้วิธีผลต่างจำกัด (Finite Difference Method) ทั้งในเชิงพื้นที่และเวลา

### คำอธิบายโค้ด Python Lab 
โค้ดด้านล่างทำการสร้างกริดเชิงพื้นที่และเวลา กำหนดเงื่อนไขขอบ (Boundary Conditions) แบบตรึงปลาย และคำนวณค่าการกระจัดของคลื่นในแต่ละช่วงเวลาด้วยอัลกอริทึม Explicit Finite Difference พร้อมทั้งบันทึกผลลัพธ์การจำลอง

```python
import numpy as np
import matplotlib.pyplot as plt

def simulate_wave_equation():
    # พารามิเตอร์ระบบ
    L = 10.0          # ความยาวเส้นลวด
    T_max = 5.0       # เวลาสิ้นสุดการจำลอง
    nx = 100          # จำนวนจุดในปริภูมิ
    dx = L / (nx - 1)
    v = 2.0           # ความเร็วคลื่น
    
    # เงื่อนไขความเสถียร Courant-Friedrichs-Lewy (CFL) condition
    dt = 0.005
    c = (v * dt / dx)**2
    assert c < 1.0, "CFL condition violated! Reduce dt."
    
    nt = int(T_max / dt)
    x = np.linspace(0, L, nx)
    
    # เมทริกซ์เก็บค่าการกระจัด u at t-dt, t, t+dt
    u = np.sin(np.pi * x / L) # เงื่อนไขเริ่มต้น (Gaussian/Sine pulse)
    u_prev = u.copy()
    u_next = np.zeros(nx)
    
    # เงื่อนไขเริ่มต้นสำหรับความเร็ว v_0 = 0 -> u_next step setup
    for i in range(1, nx - 1):
        u_next[i] = u[i] + 0.5 * c * (u[i+1] - 2*u[i] + u[i-1])
        
    print(f"Wave Simulation Initialized with {nx} spatial nodes and {nt} time steps.")
    return x, u

x_grid, u_final = simulate_wave_equation()
print("Chapter 1 Python Wave Simulation Lab Completed Successfully.")
```

## 1.7 แบบฝึกหัดทบทวนและเฉลยแนวคิด

1. **คำถาม** จงอธิบายเหตุผลทางคณิตศาสตร์ว่าเหตุใดวิธีผลต่างกึ่งกลางจึงมีความแม่นยำสูงกว่าวิธีผลต่างไปข้างหน้า
   * **แนวคิดและเฉลย** อ้างอิงจากการกระจายอนุกรมเทย์เลอร์ทั้งที่จุด $x+h$ และ $x-h$ เมื่อนำมาลบกัน พจน์อันดับคู่จะหักล้างกันไป ทำให้พจน์ความผิดพลาดเริ่มต้นที่อันดับสาม $O(h^2)$ ในขณะที่วิธีผลต่างไปข้างหน้ามีพจน์ความผิดพลาดเริ่มต้นที่อันดับสอง $O(h)$ [5]
