# โครงร่างสไลด์นำเสนอ Module 4: Machine Learning with Scikit-learn (12 Slides)

## Slide 1: Title Slide
- **Title:** Module 4: Machine Learning with Scikit-learn
- **Subtitle:** Model Selection, Hyperparameter Tuning, and Evaluation
- **Summary:** แนะนำโมดูล 4 ซึ่งเน้นการใช้ Scikit-learn ในการสร้าง, ฝึก, และประเมินโมเดล Machine Learning

## Slide 2: ML Workflow Overview
- **Title:** The Machine Learning Workflow
- **Summary:** ภาพรวมขั้นตอนการทำงานของ ML (Data Preprocessing -> Model Training -> Evaluation -> Deployment)

## Slide 3: Data Splitting and Preprocessing
- **Title:** Data Preparation: Splitting and Scaling
- **Summary:** การแบ่งข้อมูล (Train/Test/Validation Split) และความสำคัญของการปรับขนาดข้อมูล (Scaling/Normalization)

## Slide 4: Supervised Learning: Classification
- **Title:** Classification: Logistic Regression & Decision Trees
- **Summary:** แนะนำโมเดล Classification พื้นฐาน (Logistic Regression, Decision Tree) และการใช้งานใน Scikit-learn

## Slide 5: Supervised Learning: Regression
- **Title:** Regression: Linear Regression & Model Training
- **Summary:** แนะนำโมเดล Regression พื้นฐาน (Linear Regression) และขั้นตอนการ `.fit()` และ `.predict()`

## Slide 6: Model Evaluation: Classification Metrics
- **Title:** Classification Evaluation Metrics
- **Summary:** อธิบาย Metrics สำคัญ (Accuracy, Precision, Recall, F1-Score) และ Confusion Matrix

- **Title:** Regression Evaluation Metrics

- **Title:** The Bias-Variance Trade-off
- **Summary:** อธิบายปัญหา Overfitting (High Variance) และ Underfitting (High Bias) และวิธีแก้ไข

- **Title:** Robust Model Selection: Cross-Validation
- **Summary:** ความสำคัญของ Cross-Validation (K-Fold) ในการประเมินประสิทธิภาพโมเดลอย่างเป็นกลาง

## Slide 10: Hyperparameter Tuning
- **Title:** Hyperparameter Tuning: Grid Search & Random Search
- **Summary:** แนะนำเทคนิคการค้นหา Hyperparameter ที่เหมาะสมที่สุด (Grid Search CV, Randomized Search CV)
