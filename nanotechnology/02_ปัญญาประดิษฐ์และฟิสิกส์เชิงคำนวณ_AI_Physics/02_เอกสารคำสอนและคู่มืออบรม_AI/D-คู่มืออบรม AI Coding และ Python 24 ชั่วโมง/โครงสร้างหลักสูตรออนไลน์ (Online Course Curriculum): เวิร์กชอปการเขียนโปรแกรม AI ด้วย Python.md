## ภาพรวมหลักสูตร (Curriculum Overview)
หลักสูตรออนไลน์นี้ถูกพัฒนาต่อยอดโดยตรงจากคู่มือ **Professional eBook** เพื่อแปลงเนื้อหาเชิงวิชาการให้กลายเป็นประสบการณ์การเรียนรู้ออนไลน์ที่มีชีวิตชีวา เน้นการฝึกปฏิบัติจริง การทำความเข้าใจเบื้องหลังทางคณิตศาสตร์และวิศวกรรมซอฟต์แวร์ และการเตรียมความพร้อมสู่การทำงานจริงในตำแหน่ง Data Scientist หรือ AI Engineer

## รายละเอียดแต่ละโมดูล (Module Breakdown)

### โมดูลที่ 1: รากฐานโปรแกรมมิ่งและการวิเคราะห์ประสิทธิภาพ (Foundations & Time Complexity)
* **ระยะเวลา:** 4 ชั่วโมง
* **วัตถุประสงค์:** สร้างความเข้าใจที่แข็งแกร่งในโครงสร้างข้อมูลและการวัดประสิทธิภาพอัลกอริทึม
* **หัวข้อการเรียนรู้:**
  - 1.1 แนวคิดการเขียนโปรแกรม Python ขั้นสูงสำหรับงานวิเคราะห์ข้อมูล
  - 1.2 การวิเคราะห์ความซับซ้อนเชิงเวลาและพื้นที่ (Big O Notation: O(1), O(log n), O(n), O(n log n))
  - 1.3 การเลือกใช้โครงสร้างข้อมูล (List, Tuple, Dictionary, Set) ให้เหมาะสมกับงาน AI
  - 1.4 Lab: เปรียบเทียบประสิทธิภาพการค้นหาข้อมูลระหว่าง List และ Dictionary ด้วยระบบจับเวลาจริง

### โมดูลที่ 2: การเขียนโปรแกรมเชิงวัตถุเพื่อวิศวกรรม AI (OOP for AI Architecture)
* **ระยะเวลา:** 4 ชั่วโมง
* **วัตถุประสงค์:** ออกแบบสถาปัตยกรรมโค้ดให้มีความยืดหยุ่น บำรุงรักษาง่าย และสอดคล้องกับโครงสร้างของไลบรารี Deep Learning
* **หัวข้อการเรียนรู้:**
  - 2.1 สี่เสาหลักของ OOP: Encapsulation, Inheritance, Polymorphism และ Abstraction ในบริบทของ AI
  - 2.2 การสร้าง Custom Base Classes สำหรับโมเดลปัญญาประดิษฐ์
  - 2.3 การใช้งาน Magic Methods (เช่น `__call__`, `__init__`) เพื่อให้คลาสทำงานได้เหมือนฟังก์ชัน
  - 2.4 Lab: ออกแบบคลาสจัดการโมเดลโครงข่ายประสาทเทียมจำลอง

### โมดูลที่ 3: วิทยาการข้อมูลและการจัดการข้อมูลดิบ (Data Science & ML Workflow)
* **ระยะเวลา:** 4 ชั่วโมง
* **วัตถุประสงค์:** เชี่ยวชาญการจัดการ วิเคราะห์ และทำความสะอาดข้อมูลด้วย NumPy และ Pandas
* **หัวข้อการเรียนรู้:**
  - 3.1 การคำนวณเชิงตัวเลขความเร็วสูงด้วย NumPy N-dimensional Arrays และ Vectorization
  - 3.2 การสำรวจข้อมูล (Exploratory Data Analysis - EDA) และการจัดการ Missing Values ด้วย Pandas
  - 3.3 กระบวนการทำงานของ Machine Learning (Scikit-learn Workflow: Fit, Transform, Predict)
  - 3.4 Lab: วิเคราะห์ชุดข้อมูลจริงและเตรียมข้อมูลสำหรับฝึกโมเดลทำนายผล

### โมดูลที่ 4: การเรียนรู้เชิงลึกด้วย PyTorch (Deep Learning & Neural Networks)
* **ระยะเวลา:** 6 ชั่วโมง
* **วัตถุประสงค์:** เข้าใจกลไกการทำงานของ Neural Networks และสร้างโมเดล Deep Learning ด้วย PyTorch
* **หัวข้อการเรียนรู้:**
  - 4.1 สถาปัตยกรรมโครงข่ายประสาทเทียม (Artificial Neural Networks - ANN)
  - 4.2 กลไก Dynamic Computational Graph และ Autograd สำหรับการทำ Backpropagation
  - 4.3 การสร้าง Custom Dataset และ DataLoader ใน PyTorch
  - 4.4 Lab: สร้างและฝึกฝนโมเดลจำแนกข้อมูลด้วย PyTorch บน GPU Acceleration

### โมดูลที่ 5: การนำโมเดลไปใช้งานจริง (Production Deployment)
* **ระยะเวลา:** 4 ชั่วโมง
* **วัตถุประสงค์:** แปลงโมเดล AI ในห้องทดลองให้กลายเป็น RESTful API ที่พร้อมใช้งานบนระบบ Production
* **หัวข้อการเรียนรู้:**
  - 5.1 การสร้างเว็บเซอร์วิสประสิทธิภาพสูงด้วย FastAPI และ Pydantic Data Validation
  - 5.2 การจัดการ Dependencies และการทำ Containerization ด้วย Docker
  - 5.3 กลยุทธ์การทำ Model Serving และการจัดการข้อผิดพลาดในระบบจริง
  - 5.4 Lab: สร้าง Smart Housing Price Prediction API และแพ็กเกจลง Docker Container

### โมดูลที่ 6: โครงงานบูรณาการและสรุปหลักสูตร (Capstone Project & Capstone Review)
* **ระยะเวลา:** 2 ชั่วโมง
* **วัตถุประสงค์:** บูรณาการความรู้ทั้งหมดเข้าด้วยกันผ่านโครงงานจริงและการประเมินผล
* **หัวข้อการเรียนรู้:**
  - 6.1 การพัฒนา End-to-End AI Pipeline ตั้งแต่ข้อมูลดิบจนถึง Dockerized API
  - 6.2 การตรวจประเมินโค้ดและการทำ Code Review ตามมาตรฐานอุตสาหกรรม
  - 6.3 แนวทางการศึกษาต่อยอดในยุค GenAI และ Transformers
