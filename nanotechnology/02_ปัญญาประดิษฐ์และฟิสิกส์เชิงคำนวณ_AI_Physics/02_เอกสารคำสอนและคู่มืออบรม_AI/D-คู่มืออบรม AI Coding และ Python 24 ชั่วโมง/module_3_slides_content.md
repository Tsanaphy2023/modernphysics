# โครงร่างสไลด์นำเสนอ Module 3: Python for Data Analysis (12 Slides)

## Slide 1: Title Slide
- **Title:** Module 3: Python for Data Analysis
- **Subtitle:** NumPy, Pandas, and Data Visualization
- **Summary:** แนะนำโมดูล 3 ซึ่งเน้นการใช้ Python Libraries หลักสำหรับการวิเคราะห์ข้อมูล

## Slide 2: Module Overview & NumPy Introduction
- **Title:** Module 3 Overview & Why NumPy?
- **Summary:** สรุปวัตถุประสงค์ของโมดูล และความสำคัญของ NumPy ในงาน Data Science (ประสิทธิภาพ, Vectorization)

## Slide 3: NumPy: Array Creation and Indexing
- **Title:** NumPy: N-Dimensional Arrays (ndarray)
- **Summary:** การสร้าง Array (zeros, ones, arange) และเทคนิคการ Indexing/Slicing ขั้นสูง (Boolean Indexing)

## Slide 4: NumPy: Vectorization and Performance
- **Title:** Vectorization: The Power of NumPy
- **Summary:** อธิบายแนวคิด Vectorization และเปรียบเทียบประสิทธิภาพระหว่าง Python List Loop กับ NumPy Array Operation

## Slide 5: Pandas: DataFrames - The Core Structure
- **Title:** Pandas: DataFrames - The Data Structure
- **Summary:** แนะนำ DataFrame (โครงสร้างหลักของ Pandas) และการสร้าง DataFrame จากแหล่งข้อมูลต่างๆ (CSV, Dictionary)

## Slide 6: Pandas: Data Cleaning and Preprocessing
- **Title:** Data Cleaning: Handling Missing Data (NaN)
- **Summary:** เทคนิคการจัดการข้อมูลที่ขาดหาย (Missing Values) เช่น การลบ (dropna) และการเติมค่า (fillna)

## Slide 7: Pandas: Advanced Data Manipulation
- **Title:** Advanced Manipulation: GroupBy and Pivot Tables
- **Summary:** การจัดกลุ่มข้อมูลด้วย `groupby()` และการสร้างตารางสรุปด้วย `pivot_table()`

## Slide 8: Data Visualization: Matplotlib & Seaborn
- **Title:** Data Visualization: Matplotlib & Seaborn
- **Summary:** แนะนำ Matplotlib (พื้นฐาน) และ Seaborn (สถิติ) สำหรับการสร้างกราฟที่สวยงามและสื่อความหมาย

## Slide 9: Visualization: Univariate Analysis
- **Title:** Univariate Analysis: Histograms and Box Plots
- **Summary:** การใช้ Histogram เพื่อดูการกระจายตัวของข้อมูล และ Box Plot เพื่อหา Outliers

## Slide 10: Visualization: Bivariate Analysis
- **Title:** Bivariate Analysis: Scatter Plots and Heatmaps
- **Summary:** การใช้ Scatter Plot เพื่อดูความสัมพันธ์ระหว่างตัวแปร และ Heatmap เพื่อแสดง Correlation Matrix

## Slide 11: Case Study: Data Analysis Workflow
- **Title:** Case Study: End-to-End Data Analysis Workflow
- **Summary:** สรุปขั้นตอนการวิเคราะห์ข้อมูลตั้งแต่การโหลด, ทำความสะอาด, จัดกลุ่ม, จนถึงการสร้างภาพประกอบ
